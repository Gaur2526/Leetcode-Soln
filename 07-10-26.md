# 301. Remove Invalid Parentheses

Date Solved: October 7, 2026

Status: Solved

## Problem Statement

Given a string \`s\` containing lowercase English letters and parentheses, remove the minimum number of invalid parentheses to make the string valid.

Return all unique valid strings that can be obtained using the minimum number of removals.

The answer can be returned in any order.

---

## Examples

### Example 1

Input:

s = "()())()"

Output:

["(())()","()()()"]

Explanation:

Both strings are valid and require only one removal.

### Example 2

Input:

s = "(a)())()"

Output:

["(a())()","(a)()()"]

Explanation:

Both results are valid and require the minimum number of removals.

### Example 3

Input:

s = ")("

Output:

[""]

Explanation:

Both parentheses are invalid and must be removed.

---

## Constraints

\- \`1 <= s.length <= 25\`

\- \`s\` consists of lowercase English letters and parentheses \`(\` and \`)\`.

\- There will be at most \`20\` parentheses in \`s\`.

---

# Approach

We use Breadth-First Search (BFS).

The important observation is that BFS explores strings based on the number of removed characters.

For example:

Level 0:

Original string

Level 1:

Remove one parenthesis

Level 2:

Remove two parentheses

And so on.

Therefore, the first level containing valid strings represents the minimum number of removals.

### Step 1: Validate a String

We use a balance counter.

For every character:

\- \`(\` → \`balance++\`

\- \`)\` → \`balance--\`

If the balance becomes negative, there are too many closing parentheses, so the string is invalid.

After processing the complete string, the balance must be exactly \`0\`.

Therefore, a string is valid if:

\`balance >= 0\` throughout the traversal

and:

\`balance == 0\` at the end.

Letters do not affect the balance.

### Step 2: Start BFS

Put the original string into a queue.

Also maintain a set called \`visited\` so that the same string is never processed more than once.

Initially:

\`queue = [s]\`

\`visited = {s}\`

### Step 3: Generate Next Level

For every string in the current BFS level:

\- Check whether it is valid.

\- If valid, add it to the answer.

\- Otherwise, remove one parenthesis from every possible position and generate the next-level strings.

We do not remove letters because removing letters is never necessary to make parentheses valid.

### Step 4: Stop After Finding Valid Strings

Suppose valid strings are found at the current BFS level.

All strings at this level have the same number of removals.

Any string generated at the next level would require one additional removal.

Therefore, once valid strings are found, we stop generating deeper levels.

This guarantees that all returned strings use the minimum number of removals.

### Step 5: Avoid Duplicates

Different removal choices can produce the same string.

For example, removing either of two identical consecutive parentheses can produce the same result.

We use:

\`unordered_set<string> visited\`

to ensure every generated string is processed only once.

---

# Complexity

Let \`n = s.length\`.

In the worst case, we may generate exponentially many different strings.

### Time Complexity

O(2^n × n)

There can be up to O(2^n) generated strings, and validating or constructing each string can take O(n).

In practice, the constraint of at most 20 parentheses makes BFS feasible.

### Space Complexity

O(2^n × n)

The queue and visited set can contain exponentially many strings, each of length up to \`n\`.

# Solution

cpp

class Solution {

public:

    bool isValid(string s) {

        int balance = 0;

        for (char ch : s) {

            if (ch == '(') {

                balance++;

            } 
            else if (ch == ')') {

                balance--;

                if (balance < 0)

                    return false;

            }

        }

        return balance == 0;

    }

    vector<string> removeInvalidParentheses(string s) {

        vector<string> ans;

        queue<string> q;

        unordered_set<string> visited;

        q.push(s);

        visited.insert(s);

        bool found = false;

        while (!q.empty() && !found) {

            int size = q.size();

            while (size--) {

                string cur = q.front();

                q.pop();

                if (isValid(cur)) {

                    ans.push_back(cur);

                    found = true;

                    continue;

                }

                for (int i = 0; i < cur.size(); i++) {

                    if (cur[i] != '(' && cur[i] != ')')

                        continue;

                    string next = cur.substr(0, i) +

                                  cur.substr(i + 1);

                    if (!visited.count(next)) {

                        visited.insert(next);

                        q.push(next);

                    }

                }

            }

        }

        return ans;

    }

};

# Dry Run

Consider:

s = "()())()"

### Level 0

Original string:

\`()())()\`

It is not valid.

So we generate all strings by removing one parenthesis.

### Level 1

Some possible strings include:

\`()()()\`

\`(())()\`

Both are valid.

Since valid strings have been found at this level, we stop.

We do not generate level 2 because that would require an extra removal.

Final answer:

["()()()","(())()"]

---

# Key Insight

The key idea is:

BFS guarantees minimum removals.

Every BFS level represents removing exactly one additional parenthesis.

Therefore:

Level 0 → 0 removals

Level 1 → 1 removal

Level 2 → 2 removals

The first level containing valid strings gives all valid answers with the minimum number of removals.

Using a \`visited\` set prevents duplicate strings from being processed.

---

# Notes

 Use BFS because we need the minimum number of removals.

 Each BFS level represents one additional removal.

 Validate every generated string using a balance counter.

 Remove only parentheses, never letters.

 Stop searching deeper as soon as valid strings are found.

 Use a set to avoid duplicate strings.

 Multiple valid strings can exist with the same minimum number of removals.

 The input contains at most 20 parentheses, which keeps the exponential search manageable.

 Time complexity is approximately O(2^n × n).

 Space complexity is approximately O(2^n × n).
