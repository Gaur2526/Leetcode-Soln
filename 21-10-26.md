# 3863. Minimum Operations to Sort a String

Date Solved: 21 October 2026

Status: Solved

## Problem Statement

You are given a string `s` consisting of lowercase English letters.

In one operation, you can select any substring of `s` that is not the entire string and sort it in non-decreasing alphabetical order.

Return the minimum number of operations required to sort the entire string. If it is impossible, return `-1`.

---

## Examples

Example 1:

Input: `s = "dog"`

Output: `1`

Explanation:

Sort the substring `"og"` to obtain `"go"`.

The string becomes `"dgo"`, which is sorted.

Minimum operations: `1`

Example 2:

Input: `s = "card"`

Output: `2`

Explanation:

1. Sort substring `"car"` to obtain `"acr"`, giving `"acrd"`.
2. Sort substring `"rd"` to obtain `"dr"`, giving `"acdr"`.

The resulting string is sorted.

Minimum operations: `2`

Example 3:

Input: `s = "gf"`

Output: `-1`

Explanation:

The string is unsorted, and its only proper substrings have length `1`. Sorting a single character cannot change the string.

Therefore, it is impossible to sort the string.

---

## Constraints

- `1 <= s.length <= 10^5`
- `s` consists of lowercase English letters.

---

# Approach: Greedy + Boundary Analysis

We can solve the problem in `O(n)` time by analyzing the first and last characters, along with the minimum and maximum characters in the string.

Let:

- `mn` = smallest character in `s`.
- `mx` = largest character in `s`.
- `n` = length of `s`.

Case 1: The string is already sorted

If `is_sorted(s.begin(), s.end())` is true, no operations are required.

Return `0`.

Case 2: The string has length 2 and is unsorted

The only proper substrings have length `1`, so sorting them cannot change the string.

Return `-1`.

Case 3: One operation is sufficient

If either:

- `s[0] == mn`, or
- `s[n - 1] == mx`

then one operation is sufficient.

Return `1`.

Case 4: Determine whether two or three operations are needed

Define:

`minOnlyLast = (s[n - 1] == mn) && (count(s.begin(), s.end(), mn) == 1)`

This is true when the minimum character occurs exactly once and is at the last position.

Similarly:

`maxOnlyFirst = (s[0] == mx) && (count(s.begin(), s.end(), mx) == 1)`

This is true when the maximum character occurs exactly once and is at the first position.

If both conditions are true, return `3`.

Otherwise, return `2`.

Why does this work?

When the minimum is uniquely at the end and the maximum is uniquely at the beginning, neither boundary can be corrected by the usual two-operation strategy. A third operation is needed.

In all other unsorted cases with length at least `3`, two operations are sufficient.

---

# Complexity Analysis

Time Complexity: `O(n)`

- Checking whether the string is sorted takes `O(n)`.
- Finding the minimum and maximum characters takes `O(n)`.
- Counting occurrences of the minimum and maximum takes `O(n)`.

All these operations are linear.

Space Complexity: `O(1)`

Only a constant number of variables are used. The string is modified neither by the algorithm nor by the helper operations.

---

# Solution

    class Solution {
    public:
        int minOperations(string s) {
            int n = s.size();

            if (is_sorted(s.begin(), s.end())) {
                return 0;
            }

            if (n == 2) {
                return -1;
            }

            char mn = *min_element(s.begin(), s.end());
            char mx = *max_element(s.begin(), s.end());

            // One operation is sufficient.
            if (s[0] == mn || s[n - 1] == mx) {
                return 1;
            }

            // Check whether the minimum occurs only at the end.
            bool minOnlyLast =
                (s[n - 1] == mn) &&
                (count(s.begin(), s.end(), mn) == 1);

            // Check whether the maximum occurs only at the beginning.
            bool maxOnlyFirst =
                (s[0] == mx) &&
                (count(s.begin(), s.end(), mx) == 1);

            // Both boundary conditions require three operations.
            if (minOnlyLast && maxOnlyFirst) {
                return 3;
            }

            return 2;
        }
    };

# Dry Run

Example 1:

Input: `s = "dog"`

- `n = 3`
- The string is not sorted.
- `mn = 'd'`
- `mx = 'o'`

Check one-operation condition:

`s[0] == mn`

`'d' == 'd'` → true

Therefore, return `1`.

Output: `1`

Example 2:

Input: `s = "jgg"`

- `n = 3`
- The string is not sorted.
- `mn = 'g'`
- `mx = 'j'`

One-operation condition:

- `s[0] == mn` → false
- `s[n - 1] == mx` → false

Boundary conditions:

- `minOnlyLast` → true because `'g'` occurs exactly once at the last position? No: `'g'` occurs twice, so this is false.
- `maxOnlyFirst` → true because `'j'` occurs exactly once at the first position.

Both conditions are not true, so return `2`.

Output: `2`

Example 3:

Input: `s = "edc"`

- `n = 3`
- The string is not sorted.
- `mn = 'c'`
- `mx = 'e'`

One-operation condition:

- `s[0] == mn` → false
- `s[n - 1] == mx` → false

Boundary conditions:

- `minOnlyLast` → true because `'c'` occurs exactly once at the last position.
- `maxOnlyFirst` → true because `'e'` occurs exactly once at the first position.

Both conditions are true, so return `3`.

Output: `3`

Example 4:

Input: `s = "gf"`

- `n = 2`
- The string is not sorted.

Since the string has length `2`, return `-1`.

Output: `-1`

# Key Insight

The minimum and maximum characters determine how the string's boundaries can be corrected using proper-substring sorting operations.

- If the string is already sorted, return `0`.
- If an endpoint is already occupied by the appropriate extreme character, one operation is sufficient.
- If the minimum occurs only at the end and the maximum occurs only at the beginning, three operations are needed.
- Otherwise, two operations are sufficient for an unsorted string of length at least `3`.

---

# Notes

- The entire string cannot be selected as a substring.
- An unsorted string of length `2` cannot be sorted.
- Repeated minimum or maximum characters can change the answer by avoiding the three-operation case.
- `is_sorted()` checks whether the string is already in non-decreasing order.
- `min_element()` and `max_element()` identify the extreme characters.
- `count()` determines whether an extreme character occurs exactly once.
- The solution runs in `O(n)` time and uses `O(1)` extra space.
