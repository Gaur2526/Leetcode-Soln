# 856. Score of Parentheses

Date Solved: October 5, 2026

Status: Solved

## Problem Statement

Given a balanced parentheses string \`s\`, return the score of the string.

The score is defined using these rules:

\- \`()\` has score \`1\`.

\- \`AB\` has score \`A + B\`, where \`A\` and \`B\` are balanced parentheses strings.

\- \`(A)\` has score \`2 * A\`.

---

## Examples

### Example 1

Input:

s = "()"

Output:

1

### Example 2

Input:

s = "(())"

Output:

2

Explanation:

\`(())\` = \`2 * ()\`

So:

\`2 * 1 = 2\`

### Example 3

Input:

s = "()()"

Output:

2

Explanation:

\`()() = () + ()\`

Score:

\`1 + 1 = 2\`

---

## Constraints

\- \`2 <= s.length <= 50\`

\- \`s\` consists of only \`(\` and \`)\`.

\- \`s\` is a balanced parentheses string.

---

# Approach

We use a stack to store the score of each nesting level.

Each opening parenthesis creates a new level with an initial score of \`0\`.

When we encounter a closing parenthesis, we calculate the score of the current level and add it to the parent level.

### Step 1: Initialize the Stack

Push \`0\` into the stack.

This represents the score at the outermost level.

For example:

\`()\`

Initial stack:

\`[0]\`

### Step 2: Handle Opening Parenthesis

When we see \`(\`, push \`0\`.

This creates a new nesting level.

For:

\`(())\`

After reading the first two characters:

\`(\`

\`((\`

Stack:

\`[0, 0, 0]\`

### Step 3: Handle Closing Parenthesis

When we see \`)\`, look at the score of the current level.

There are two cases.

Case 1: Inner score is 0

If:

\`inner == 0\`

then the current pair is simply:

\`()\`

Its score is:

\`1\`

Case 2: Inner score is greater than 0

The current expression has the form:

\`(A)\`

According to the rule:

\`score = 2 * A\`

So:

\`score = 2 * inner\`

After calculating the score, add it to the parent level.

### Step 4: Combine Adjacent Expressions

For:

\`()()\`

The first \`()\` contributes \`1\`.

The second \`()\` contributes another \`1\`.

So the outer level becomes:

\`1 + 1 = 2\`

This naturally handles the rule:

\`AB = A + B\`

---

# Complexity

### Time Complexity

O(n)

We process every character exactly once.

### Space Complexity

O(n)

In the worst case, the parentheses can be completely nested, so the stack can contain O(n) elements.

---

# Solution

cpp

class Solution {

public:

    int scoreOfParentheses(string s) {

        stack<int> st;

        st.push(0);

        for (char ch : s) {

            if (ch == '(') {

                st.push(0);

            } 
            else {

                int inner = st.top();

                st.pop();

                int score = (inner == 0) ? 1 : 2 * inner;

                st.top() += score;

            }

        }

        return st.top();

    }

};

# Dry Run

Consider:

s = "(())"

### Character 1: \`(\`

Push a new level.

Stack:

\`[0, 0]\`

### Character 2: \`(\`

Push another level.

Stack:

\`[0, 0, 0]\`

### Character 3: \`)\`

Current inner score:

\`0\`

Therefore this is:

\`()\`

Score:

\`1\`

Pop the current level and add \`1\` to the parent.

Stack:

\`[0, 0, 1]\` → after pop/add conceptually:

\`[0, 1]\`

### Character 4: \`)\`

Current inner score:

\`1\`

So this is:

\`(A)\`

Score:

\`2 * 1 = 2\`

Add \`2\` to the outer level.

Stack:

\`[2]\`

Final answer:

2

---

# Key Insight

The most important observation is:

\`() = 1\`

and:

\`(A) = 2 * A\`

A stack lets us calculate the score from the inside out.

When closing a parenthesis:

\- Inner score \`0\` → it was \`()\` → score \`1\`.

\- Inner score \`> 0\` → it was \`(A)\` → score \`2 * inner\`.

The calculated score is then added to the parent level.

---

# Notes

 Use a stack to represent different nesting levels.

 Push \`0\` for every opening parenthesis.

 For a closing parenthesis, calculate the score of the current level.

 \`()\` contributes \`1\`.

 \`(A)\` contributes \`2 * A\`.

 Add the calculated score to the parent level.

 Adjacent balanced strings are automatically added together.

 The input is guaranteed to be balanced, so no invalid-parentheses checks are required.

 Time complexity is O(n).

 Space complexity is O(n).
