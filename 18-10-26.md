# 1569. Number of Ways to Reorder Array to Get Same BST

Date Solved: 18 October 2026

Status: Solved

## Problem Statement

You are given an array `nums` representing a permutation of integers from `1` to `n`.

The elements are inserted into an initially empty Binary Search Tree (BST) in the order given by `nums`.

Return the number of different reorderings of `nums` that produce the same BST as the original array.

Since the answer can be very large, return the result modulo `10^9 + 7`.

Important: The original ordering is included in the count, but the problem asks for the number of other reorderings. Therefore, subtract `1` from the final result.

---

## Examples

Example 1:

Input: `nums = [2,1,3]`

Output: `1`

Explanation:

The original ordering creates a BST with root `2`, left child `1`, and right child `3`.

The reordering `[2,3,1]` creates the same BST.

There is exactly one other valid ordering.

Example 2:

Input: `nums = [3,4,5,1,2]`

Output: `5`

Explanation:

The following reorderings produce the same BST:

- `[3,1,2,4,5]`
- `[3,1,4,2,5]`
- `[3,1,4,5,2]`
- `[3,4,1,2,5]`
- `[3,4,1,5,2]`

There are five valid reorderings other than the original.

Example 3:

Input: `nums = [1,2,3]`

Output: `0`

Explanation:

The original ordering creates a right-skewed BST.

No other ordering produces the same BST, so the answer is `0`.

---

## Constraints

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= nums.length`
- All integers in `nums` are distinct.

---

# Approach: Recursion + Combinatorics

The first element of `nums` always becomes the root of the BST.

For every remaining element:

- If it is smaller than the root, it belongs to the left subtree.
- If it is greater than the root, it belongs to the right subtree.

To construct the same BST, the relative insertion order within each subtree must preserve its structure. However, the elements belonging to the left and right subtrees can be interleaved in different ways.

Suppose:

- `L` is the number of elements in the left subtree.
- `R` is the number of elements in the right subtree.

After recursively counting the valid reorderings of both subtrees, we can interleave their elements in:

`C(L + R, L)`

ways.

Therefore, the number of reorderings for the current subtree is:

`ways = C(L + R, L) * leftWays * rightWays`

All calculations are performed modulo `10^9 + 7`.

Step 1: Precompute combinations

Use Pascal's identity:

`C(n, r) = C(n - 1, r - 1) + C(n - 1, r)`

Base cases:

- `C(n, 0) = 1`
- `C(n, n) = 1`

Precompute the combination table in `O(n²)` time.

Step 2: Recursively divide the array

For each recursive call:

1. Take the first element as the root.
2. Divide the remaining elements into `left` and `right`.
3. Recursively calculate the valid reorderings for both subtrees.
4. Multiply the left and right results by the number of ways to interleave their elements.

Step 3: Exclude the original ordering

The recursive result includes the original array itself.

Therefore, return:

`(dfs(nums) - 1 + MOD) % MOD`

Adding `MOD` prevents a negative result when the count is `0` modulo `MOD`.

---

# Complexity Analysis

Time Complexity: `O(n²)`

- Precomputing combinations takes `O(n²)`.
- Recursive partitioning processes the array in at most `O(n²)` total time.
- Combination lookups take `O(1)` time.

Space Complexity: `O(n²)`

- The combination table requires `O(n²)` space.
- Recursive calls and temporary subtree vectors require additional space, bounded by `O(n²)` in the worst case.

# Solution

    class Solution {
        static const int MOD = 1e9 + 7;
        vector<vector<long long>> comb;

        long long dfs(vector<int>& nums) {
            int n = nums.size();

            if (n <= 2) {
                return 1;
            }

            vector<int> left, right;

            for (int i = 1; i < n; i++) {
                if (nums[i] < nums[0]) {
                    left.push_back(nums[i]);
                } else {
                    right.push_back(nums[i]);
                }
            }

            long long leftWays = dfs(left);
            long long rightWays = dfs(right);

            long long ways = comb[n - 1][left.size()];
            ways = ways * leftWays % MOD;
            ways = ways * rightWays % MOD;

            return ways;
        }

    public:
        int numOfWays(vector<int>& nums) {
            int n = nums.size();

            comb.assign(n + 1, vector<long long>(n + 1, 0));

            for (int i = 0; i <= n; i++) {
                comb[i][0] = comb[i][i] = 1;

                for (int j = 1; j < i; j++) {
                    comb[i][j] =
                        (comb[i - 1][j - 1] +
                         comb[i - 1][j]) % MOD;
                }
            }

            return (dfs(nums) - 1 + MOD) % MOD;
        }
    };

# Dry Run

Input: `nums = [2,1,3]`

Step 1: Identify the root

The first element is `2`.

- Left subtree: `[1]`
- Right subtree: `[3]`

Thus:

- `L = 1`
- `R = 1`

Step 2: Count reorderings of each subtree

Both subtrees contain only one element.

Therefore:

- `leftWays = 1`
- `rightWays = 1`

Step 3: Calculate the interleavings

We can choose the position of the left-subtree element among the two remaining positions in:

`C(2,1) = 2` ways.

Therefore:

`ways = C(2,1) * 1 * 1`

`ways = 2`

The two orderings are:

- `[2,1,3]`
- `[2,3,1]`

Step 4: Exclude the original ordering

`answer = ways - 1`

`answer = 2 - 1 = 1`

Final Output: `1`

---

# Key Insight

The root must remain first, but the elements from its left and right subtrees can be interleaved as long as their relative insertion orders are preserved.

The number of possible interleavings is given by a binomial coefficient.

Recursively combining the counts for both subtrees gives the total number of reorderings that construct the same BST.

# Notes

- The first element always determines the root.
- Smaller elements belong to the left subtree; larger elements belong to the right subtree.
- Use combinations to count the ways of interleaving left and right subtree elements.
- Precompute combinations with Pascal's triangle to avoid repeated calculations.
- The recursive base case `n <= 2` returns `1`.
- Subtract `1` to exclude the original ordering.
- Apply modulo `10^9 + 7` throughout the calculations.
- The algorithm takes `O(n²)` time and uses `O(n²)` space.
- The three provided examples have expected outputs `1`, `5`, and `0`.
