# 1621. Number of Sets of K Non-Overlapping Line Segments

Date Solved: September 16, 2026

Status: Solved

## Problem Statement

Given `n` points on a 1-D plane, where the `ith` point (from `0` to `n-1`) is at `x = i`, find the number of ways we can draw exactly `k` non-overlapping line segments such that each segment covers two or more points.

The endpoints of each segment must have integral coordinates.

The `k` line segments:

- Do not overlap.

- Are allowed to share endpoints.

- Do not have to cover all `n` points.

Return the number of ways to draw exactly `k` non-overlapping line segments.

Since this number can be huge, return it modulo `10^9 + 7`.

---

## Examples

### Example 1

Input:

`n = 4, k = 2`

Output:

`5`

Explanation:

The five different ways are:

`{(0,2),(2,3)}`

`{(0,1),(1,3)}`

`{(0,1),(2,3)}`

`{(1,2),(2,3)}`

`{(0,1),(1,2)}`

The segments are allowed to share endpoints, so configurations such as `(0,1)` and `(1,2)` are valid.

### Example 2

Input:

`n = 3, k = 1`

Output:

`3`

Explanation:

The three possible segments are:

`{(0,1)}`

`{(0,2)}`

`{(1,2)}`

### Example 3

Input:

`n = 30, k = 7`

Output:

`796297179`

Explanation:

The total number of possible ways to draw 7 line segments is `3796297200`.

Taking this number modulo `10^9 + 7` gives `796297179`.

---

## Constraints

- `2 <= n <= 1000`

- `1 <= k <= n - 1`

---

# Approach

We can solve this problem using a combinatorial observation.

For exactly `k` line segments, we need to choose 2k endpoints.

The important part is that consecutive segments are allowed to share endpoints.

For example:

`(0,1)` and `(1,2)`

are valid because the segments only touch at endpoint `1` and do not overlap.

After accounting for the possibility of shared endpoints, the problem can be transformed into choosing `2k` positions from `n + k - 1` positions.

Therefore, the answer is:

`C(n + k - 1, 2k)`

So the problem reduces to calculating a binomial coefficient modulo `10^9 + 7`.

---

## Step 1: Understand the Combination Formula

Suppose we have `k` segments:

`[a1, b1], [a2, b2], ..., [ak, bk]`

Since the segments cannot overlap, their endpoints must satisfy:

`a1 < b1 <= a2 < b2 <= ... <= ak < bk`

Notice that:

- The start and end of the same segment must be different.

- Two consecutive segments are allowed to have the same endpoint.

For example:

`(0,1), (1,2)`

is valid.

We can transform these constraints into a standard increasing-selection problem.

After applying the transformation, choosing `k` non-overlapping segments becomes equivalent to choosing `2k` positions from:

`n + k - 1`

positions.

Therefore:

`Answer = C(n + k - 1, 2k)`

---

## Step 2: Verify the Formula

For:

`n = 4, k = 2`

we get:

`C(n + k - 1, 2k)`

`= C(4 + 2 - 1, 4)`

`= C(5, 4)`

`= 5`

which matches the expected answer.

For:

`n = 3, k = 1`

we get:

`C(3 + 1 - 1, 2)`

`= C(3, 2)`

`= 3`

which also matches the expected answer.

---

## Step 3: Calculate the Combination

We need to calculate:

`C(n + k - 1, 2k)`

Since:

`n <= 1000`

we have:

`n + k - 1 <= 1998`

so the values are small enough to calculate using Pascal's Triangle.

The standard recurrence is:

`C(i, j) = C(i - 1, j) + C(i - 1, j - 1)`

Instead of storing the complete 2D Pascal's Triangle, we can use a 1D DP array.

Let:

`dp[j]`

represent the current value of:

`C(i, j)`

We update the values from right to left:

`dp[j] = dp[j] + dp[j - 1]`

Updating from right to left is important because it prevents the current row from overwriting values that are still needed from the previous row.

---

## Step 4: Space Optimization

A complete Pascal's Triangle would require:

`O(nk)`

space.

However, each value only depends on the previous row.

Therefore, we only need one array of size:

`2k + 1`

This reduces the space complexity to:

`O(k)`

---

## Detailed Steps

1. Let `N = n + k - 1`.

2. We need to calculate:

   `C(N, 2k)`.

3. Create a 1D DP array of size `2k + 1`.

4. Initialize:

   `dp[0] = 1`.

5. Iterate `i` from `1` to `N`.

6. For every `i`, update `j` from right to left.

7. Apply:

   `dp[j] = (dp[j] + dp[j - 1]) % MOD`.

8. After processing all values up to `N`, `dp[2k]` contains:

   `C(N, 2k)`.

9. Return `dp[2k]`.

---

# Complexity

Let:

`N = n + k - 1`.

## Time Complexity

We calculate the required row of Pascal's Triangle.

For every value of `i`, we process at most `2k` values.

Therefore:

`Time: O(n * k)`

## Space Complexity

We only store `2k + 1` values.

Therefore:

`Space: O(k)`

---

# Solution

```cpp

class Solution {

public:

    static const int MOD = 1000000007;

    int numberOfSets(int n, int k) {

        int N = n + k - 1;

        // dp[j] represents C(current_i, j)

        vector<long long> dp(2 * k + 1, 0);

        dp[0] = 1;

        // Build Pascal's Triangle using 1D DP

        for (int i = 1; i <= N; i++) {

            // Update from right to left

            for (int j = min(i, 2 * k); j >= 1; j--) {

                dp[j] = (dp[j] + dp[j - 1]) % MOD;

            }

        }

        return dp[2 * k];

    }

};

```

# Key Insight

The main insight is that we do not need to explicitly generate every possible line segment.

For `k` segments, there are `2k` endpoints.

Because adjacent segments are allowed to share endpoints, the ordering constraints can be transformed into selecting `2k` distinct positions from `n + k - 1` positions.

Therefore, the problem reduces to the binomial coefficient:

`C(n + k - 1, 2k)`

Once this formula is identified, we only need to calculate the combination efficiently under modulo `10^9 + 7`.

Using Pascal's Triangle with 1D DP gives an efficient:

`O(n * k)`

time and:

`O(k)`

space solution.

# Notes

- Each segment must cover at least two points, so its two endpoints must be different.

- Consecutive segments are allowed to share endpoints.

- The segments do not have to cover every point.

- The order of the segments does not matter because we are counting sets of segments.

- The final combinatorial formula is:

  `C(n + k - 1, 2k)`.

- Pascal's Triangle avoids the need for modular inverse and factorial calculations.

- Using a 1D DP array reduces the space complexity from `O(nk)` to `O(k)`.
