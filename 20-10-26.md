# 3886. Sum of Sortable Integers

Date Solved: 20 October 2026

Status: Solved

## Problem Statement

You are given an integer array `nums` of length `n`.

An integer `k` is called sortable if:

1. `k` divides `n`.
2. The array can be partitioned into consecutive subarrays of length `k`.
3. Each subarray can be independently rotated cyclically to the left or right any number of times so that the entire array becomes sorted in non-decreasing order.

Return the sum of all possible sortable values of `k`.

---

## Examples

Example 1:

Input: `nums = [3,1,2]`

Output: `3`

Explanation:

The divisors of `n = 3` are `1` and `3`.

- `k = 1`: Each block contains one element. The array cannot be sorted.
- `k = 3`: The entire array `[3,1,2]` can be rotated to obtain `[1,2,3]`.

Only `k = 3` is sortable.

Answer: `3`

Example 2:

Input: `nums = [7,6,5]`

Output: `0`

Explanation:

The divisors are `1` and `3`.

- `k = 1`: The array cannot be changed.
- `k = 3`: No cyclic rotation of `[7,6,5]` produces `[5,6,7]`.

No value of `k` is sortable.

Answer: `0`

Example 3:

Input: `nums = [5,8]`

Output: `3`

Explanation:

The divisors of `n = 2` are `1` and `2`.

- `k = 1`: The array is already sorted.
- `k = 2`: The entire array is already sorted.

Both values are sortable.

Answer: `1 + 2 = 3`

---

## Constraints

- `1 <= n == nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

---

# Approach: Divisors + KMP Pattern Matching

We need to find every divisor `k` of `n` for which every block of length `k` can be rotated into its corresponding segment in the globally sorted array.

Checking every possible value of `k` is unnecessary because only divisors of `n` are valid candidates.

Step 1: Create the sorted array

Make a sorted copy of `nums`, called `sortedNums`.

The final array must equal `sortedNums`.

Step 2: Enumerate divisors

Iterate through integers `d` while `d * d <= n`.

Whenever `n % d == 0`, both `d` and `n / d` are divisors.

Check each divisor, ensuring that a square-root divisor is not checked twice.

Step 3: Check every block

For a candidate `k`, divide the original array into blocks of length `k`.

For each block starting at index `start`, compare it with the corresponding segment of `sortedNums`.

The block is valid if it is a cyclic rotation of that target segment.

Step 4: Use KMP to check cyclic rotations

Suppose the original block is:

`[3,1,2]`

Its cyclic rotations include:

- `[3,1,2]`
- `[1,2,3]`
- `[2,3,1]`

A block is a cyclic rotation of another sequence if its target sequence appears in the original block repeated twice, with the final repeated element excluded.

For example:

`[3,1,2,3,1]`

contains `[1,2,3]`.

We use the Knuth-Morris-Pratt (KMP) algorithm to check this efficiently in `O(k)` time.

Step 5: Calculate the answer

If every block passes the rotation check, add `k` to the answer.

After checking all divisors, return the sum.

---

# Complexity Analysis

Let `τ(n)` denote the number of divisors of `n`.

Time Complexity: `O(n log n + n * τ(n))`

- Sorting the array takes `O(n log n)`.
- Each candidate divisor requires `O(n)` total time to check all blocks using KMP.
- There are `τ(n)` divisors.

Space Complexity: `O(n)`

The sorted copy requires `O(n)` space. The KMP pattern and prefix table require `O(k)` temporary space.

# Solution

    class Solution {
        bool isRotation(vector<int>& nums, vector<int>& sortedNums,
                        int start, int k) {
            vector<int> pattern(k);

            for (int i = 0; i < k; i++) {
                pattern[i] = sortedNums[start + i];
            }

            vector<int> lps(k, 0);

            for (int i = 1, len = 0; i < k;) {
                if (pattern[i] == pattern[len]) {
                    lps[i++] = ++len;
                } else if (len > 0) {
                    len = lps[len - 1];
                } else {
                    lps[i++] = 0;
                }
            }

            int j = 0;

            for (int i = 0; i < 2 * k - 1; i++) {
                int value = nums[start + i % k];

                while (j > 0 && value != pattern[j]) {
                    j = lps[j - 1];
                }

                if (value == pattern[j]) {
                    j++;
                }

                if (j == k) {
                    return true;
                }
            }

            return false;
        }

        bool check(vector<int>& nums, vector<int>& sortedNums, int k) {
            int n = nums.size();

            for (int start = 0; start < n; start += k) {
                if (!isRotation(nums, sortedNums, start, k)) {
                    return false;
                }
            }

            return true;
        }

    public:
        int sumSortable(vector<int>& nums) {
            int n = nums.size();

            vector<int> sortedNums = nums;
            sort(sortedNums.begin(), sortedNums.end());

            int ans = 0;

            for (int d = 1; d * d <= n; d++) {
                if (n % d != 0) {
                    continue;
                }

                if (check(nums, sortedNums, d)) {
                    ans += d;
                }

                int other = n / d;

                if (other != d && check(nums, sortedNums, other)) {
                    ans += other;
                }
            }

            return ans;
        }
    };

# Dry Run

Input: `nums = [3,1,2]`

Step 1: Sort the array

Original array:

`[3,1,2]`

Sorted array:

`[1,2,3]`

Array length:

`n = 3`

Step 2: Find the divisors

The divisors of `3` are:

`1, 3`

Step 3: Check `k = 1`

The blocks are:

- `[3]`, target `[1]`
- `[1]`, target `[2]`
- `[2]`, target `[3]`

None of these mismatched single-element blocks can be changed through rotation.

Therefore, `k = 1` is not sortable.

Running answer: `0`

Step 4: Check `k = 3`

There is only one block:

`Original block = [3,1,2]`

`Target block = [1,2,3]`

Cyclic rotations of the original block include:

- `[3,1,2]`
- `[1,2,3]`
- `[2,3,1]`

The target block is a valid cyclic rotation.

Therefore, `k = 3` is sortable.

Running answer:

`0 + 3 = 3`

Final Output: `3`

# Key Insight

A block must be a cyclic rotation of its corresponding segment in the globally sorted array.

Checking whether each block can be sorted independently is insufficient because rotations preserve the circular order of elements.

By checking only divisors of `n` and using KMP to test cyclic rotations, we can solve the problem efficiently.

---

# Notes

- Only divisors of `n` can be valid values of `k`.
- Each block must become its exact corresponding segment in the sorted array.
- Cyclic rotation preserves the relative circular order of elements.
- KMP checks whether the target segment occurs in the doubled block.
- The doubled block needs only `2 * k - 1` elements to test every possible rotation.
- Each candidate divisor takes `O(n)` time to check.
- The solution uses `O(n log n + n * τ(n))` time and `O(n)` auxiliary space.
- The three provided examples have expected outputs `3`, `0`, and `3`.
