# 2913. Subarrays Distinct Element Sum of Squares I

Date Solved: 15 October 2026

Status: Solved

## Problem Statement

You are given a 0-indexed integer array `nums`.

The distinct count of a subarray is the number of unique elements present in that subarray.

A subarray is a contiguous, non-empty sequence of elements within an array.

Return the sum of the squares of the distinct counts of all possible subarrays of `nums`.

---

## Examples

Example 1:

Input: `nums = [1,2,1]`

Output: `15`

Explanation:

There are six possible subarrays:

- `[1]` → 1 distinct element → \(1^2 = 1\)
- `[2]` → 1 distinct element → \(1^2 = 1\)
- `[1]` → 1 distinct element → \(1^2 = 1\)
- `[1,2]` → 2 distinct elements → \(2^2 = 4\)
- `[2,1]` → 2 distinct elements → \(2^2 = 4\)
- `[1,2,1]` → 2 distinct elements → \(2^2 = 4\)

Total:

\(1 + 1 + 1 + 4 + 4 + 4 = 15\)

Example 2:

Input: `nums = [1,1]`

Output: `3`

Explanation:

The possible subarrays are:

- `[1]` → 1 distinct element → \(1^2 = 1\)
- `[1]` → 1 distinct element → \(1^2 = 1\)
- `[1,1]` → 1 distinct element → \(1^2 = 1\)

Total:

\(1 + 1 + 1 = 3\)

---

## Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

---

# Approach: Brute Force + Hash Set

Since the array length is at most `100`, we can efficiently examine every possible subarray.

We use an `unordered_set` to maintain the distinct elements in the current subarray.

Steps:

1. Initialize `ans = 0`.
2. Fix the starting index `i` from `0` to `n - 1`.
3. Create an empty `unordered_set` for each starting index.
4. Extend the subarray by moving the ending index `j` from `i` to `n - 1`.
5. Insert `nums[j]` into the set.
6. The number of distinct elements is `st.size()`.
7. Add the square of this distinct count to `ans`.
8. Return `ans` after processing all subarrays.

Why does this work?

Every non-empty subarray has a unique starting and ending index pair `(i, j)`. By considering every such pair, we process every possible subarray exactly once.

The set automatically handles duplicates, so its size always represents the number of distinct elements in the current subarray.

---

# Complexity Analysis

Time Complexity: `O(n²)` average

There are `O(n²)` possible subarrays. Each set insertion takes `O(1)` average time.

Space Complexity: `O(n)`

The set can store at most `n` distinct elements.

---

# Solution

    class Solution {
    public:
        int sumCounts(vector<int>& nums) {
            int n = nums.size();
            int ans = 0;

            for (int i = 0; i < n; i++) {
                unordered_set<int> st;

                for (int j = i; j < n; j++) {
                    st.insert(nums[j]);

                    int distinct = st.size();
                    ans += distinct * distinct;
                }
            }

            return ans;
        }
    };

# Key Insight

Fix the starting index and extend the ending index one element at a time.

Maintain a set of distinct elements for the current subarray. Every time an element is added, calculate the square of the set size and add it to the answer.

This avoids recomputing distinct counts from scratch for every subarray.

---

# Notes

- A subarray must be contiguous and non-empty.
- Use `unordered_set` to track unique elements.
- Reset the set whenever the starting index changes.
- Duplicate elements do not increase the distinct count.
- The answer fits in an `int` under the given constraints.
- The solution runs in `O(n²)` average time and uses `O(n)` extra space.
- Verified against both provided examples: outputs are `15` and `3`.
