# 2089. Find Target Indices After Sorting Array

Date Solved: 19 October 2026

Status: Solved

## Problem Statement

You are given a 0-indexed integer array `nums` and an integer `target`.

A target index is an index `i` such that `nums[i] == target`.

Return a list of all target indices after sorting `nums` in non-decreasing order.

The returned indices must be sorted in increasing order. If the target does not exist in the array, return an empty list.

---

## Examples

Example 1:

Input: `nums = [1,2,5,2,3]`, `target = 2`

Output: `[1,2]`

Explanation:

After sorting, the array becomes:

`[1,2,2,3,5]`

The target `2` appears at indices `1` and `2`.

Example 2:

Input: `nums = [1,2,5,2,3]`, `target = 3`

Output: `[3]`

Explanation:

After sorting:

`[1,2,2,3,5]`

The target `3` appears at index `3`.

Example 3:

Input: `nums = [1,2,5,2,3]`, `target = 5`

Output: `[4]`

Explanation:

After sorting:

`[1,2,2,3,5]`

The target `5` appears at index `4`.

---

## Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i], target <= 100`

---

# Approach: Sorting + Linear Search

The simplest approach is to sort the array first and then find all indices containing the target.

Steps:

1. Sort `nums` in non-decreasing order.
2. Create an empty vector `ans`.
3. Traverse the sorted array from index `0` to `n - 1`.
4. If `nums[i] == target`, add index `i` to `ans`.
5. Return `ans`.

Because we traverse the array from left to right, the collected indices are automatically in increasing order.

---

# Complexity Analysis

Time Complexity: `O(n log n)`

Sorting takes `O(n log n)` time, and traversing the array takes `O(n)` time.

Space Complexity: `O(1)` auxiliary space, excluding the result vector, depending on the sorting implementation.

---

# Solution

    class Solution {
    public:
        vector<int> targetIndices(vector<int>& nums, int target) {
            sort(nums.begin(), nums.end());

            vector<int> ans;

            for (int i = 0; i < nums.size(); i++) {
                if (nums[i] == target) {
                    ans.push_back(i);
                }
            }

            return ans;
        }
    };

# Dry Run

Input:

`nums = [1,2,5,2,3]`

`target = 2`

Step 1: Sort the array

Original array:

`[1,2,5,2,3]`

Sorted array:

`[1,2,2,3,5]`

Step 2: Traverse the sorted array

| Index `i` | `nums[i]` | Condition | Result |
|---|---:|---|---|
| 0 | 1 | `1 == 2` is false | `[]` |
| 1 | 2 | `2 == 2` is true | `[1]` |
| 2 | 2 | `2 == 2` is true | `[1,2]` |
| 3 | 3 | `3 == 2` is false | `[1,2]` |
| 4 | 5 | `5 == 2` is false | `[1,2]` |

Final Output:

`[1,2]`

---

# Key Insight

After sorting, all occurrences of the target appear consecutively.

We can collect their indices in a single traversal. Since the traversal proceeds from left to right, the result is automatically sorted.
