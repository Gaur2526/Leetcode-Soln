# 1658. Minimum Operations to Reduce X to Zero

Date Solved: September 23, 2026
Status: Solved

## Problem Statement

You are given an integer array nums and an integer x.

In one operation, you can remove either the leftmost or the rightmost element from nums and subtract its value from x.

Return the minimum number of operations required to reduce x to exactly 0.

If it is impossible, return -1.

---

## Examples

### Example 1

Input:
nums = [1,1,4,2,3], x = 5

Output:
2

Explanation:

Remove the last two elements:

3 + 2 = 5

So the answer is 2.

### Example 2

Input:
nums = [5,6,7,8,9], x = 4

Output:
-1

Explanation:

No combination of elements removed from the two ends can sum to 4.

### Example 3

Input:
nums = [3,2,20,1,1,3], x = 10

Output:
5

Explanation:

Remove the last three elements and the first two elements:

3 + 2 + 1 + 1 + 3 = 10

Therefore, the answer is 5.

---

## Constraints

 1 <= nums.length <= 10^5
 1 <= nums[i] <= 10^4
 1 <= x <= 10^9

---

# Approach

Instead of thinking about which elements to remove, think about which elements we can keep.

Suppose the total sum of the array is:

total

If the removed elements must sum to x, then the elements we keep must have sum:

target = total - x

Therefore, we need to find the longest subarray whose sum is exactly target.

Once we find that subarray, everything outside it can be removed from the left and right.

If the longest subarray has length maxLen, then the minimum number of operations is:

n - maxLen

### Step 1: Calculate Total Sum

Calculate:

total = sum(nums)

Then:

target = total - x

### Step 2: Handle Impossible Cases

If:

target < 0

then the total sum is smaller than x, so it is impossible.

If:

target == 0

we must remove every element, so the answer is:

n

### Step 3: Use Sliding Window

All elements are positive, so a sliding window can find the longest subarray with sum target.

Maintain:

 left → left boundary of the window.
 right → right boundary.
 sum → current window sum.
 maxLen → longest valid window found.

For every right:

1. Add nums[right] to sum.
2. While sum > target, move left forward.
3. If sum == target, update maxLen.

### Step 4: Calculate the Answer

If no valid subarray exists:

return -1

Otherwise:

answer = n - maxLen

---

# Complexity

### Time Complexity

O(n)

Each element enters and leaves the sliding window at most once.

### Space Complexity

O(1)

Only a few variables are used.

---

# Solution

cpp
class Solution {
public:
    int minOperations(vector<int>& nums, int x) {
        int n = nums.size();
        long long total = 0;

        for (int num : nums) {
            total += num;
        }

        long long target = total - x;

        if (target < 0) {
            return -1;
        }

        if (target == 0) {
            return n;
        }

        long long sum = 0;
        int left = 0;
        int maxLen = -1;

        for (int right = 0; right < n; right++) {
            sum += nums[right];

            while (left <= right && sum > target) {
                sum -= nums[left++];
            }

            if (sum == target) {
                maxLen = max(maxLen, right - left + 1);
            }
        }

        return maxLen == -1 ? -1 : n - maxLen;
    }
};

# Dry Run

Consider:

nums = [1,1,4,2,3]

x = 5

Step 1: Total Sum

total = 1 + 1 + 4 + 2 + 3 = 11

Therefore:

target = 11 - 5 = 6

We need the longest subarray with sum 6.

Step 2: Sliding Window

Start with:

left = 0

Add elements:

[1]` → sum = 1

[1,1]` → sum = 2

[1,1,4]` → sum = 6

We found a valid subarray:

[1,1,4]

Length:

3

Continue:

Add 2:

sum = 8

Remove from the left:

8 - 1 = 7

Remove again:

7 - 1 = 6

Now:

[4,2]

Length:

2

Add 3:

sum = 9

Remove 4:

9 - 4 = 5

No longer valid.

The longest valid subarray has length 3.

Step 3: Calculate Operations

Array length:

n = 5

Longest kept subarray:

maxLen = 3

Therefore:

5 - 3 = 2

Answer: 2

# Key Insight

The important transformation is:

Minimum elements to remove = Total elements - Maximum elements we can keep

If the removed elements sum to x, the kept elements must sum to:

totalSum - x

So the problem becomes finding the longest subarray with sum totalSum - x.

Because all numbers are positive, the sliding window technique works in O(n).

# Notes

 Think about the elements we keep instead of the elements we remove.
 The target kept sum is totalSum - x.
 Positive numbers allow us to use a sliding window.
 If totalSum < x, the answer is -1.
 If totalSum == x, remove all elements, so the answer is n.
 Use long long for the total sum because the sum can exceed the range of int.
 Final answer is n - maxLen.
