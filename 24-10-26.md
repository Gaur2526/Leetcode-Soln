# 2409. Count Days Spent Together

Date Solved: 24 October 2026

Status: Solved

## Problem Statement

Alice and Bob are traveling to Rome for separate business meetings.

You are given four strings:

- `arriveAlice`: Alice's arrival date.
- `leaveAlice`: Alice's departure date.
- `arriveBob`: Bob's arrival date.
- `leaveBob`: Bob's departure date.

Each date is represented as a five-character string in the format `"MM-DD"`.

Alice and Bob are in Rome from their arrival dates to their departure dates, inclusive.

Return the total number of days they spend in Rome together.

All dates belong to the same non-leap year.

---

## Examples

Example 1

Input:
```cpp
arriveAlice = "08-15"
leaveAlice = "08-18"
arriveBob = "08-16"
leaveBob = "08-19"
```

Output:
```cpp
3
```

Explanation:

Alice stays from August 15 to August 18.

Bob stays from August 16 to August 19.

They are together on August 16, 17, and 18.

Total = 3 days.

Example 2

Input:
```cpp
arriveAlice = "10-01"
leaveAlice = "10-31"
arriveBob = "11-01"
leaveBob = "12-31"
```

Output:
```cpp
0
```

Explanation:

Alice leaves on October 31, while Bob arrives on November 1.

They have no overlapping days.

## Constraints

- All dates are provided in the format `"MM-DD"`.
- Alice's arrival date is earlier than or equal to her departure date.
- Bob's arrival date is earlier than or equal to his departure date.
- All dates are valid dates in a non-leap year.

# Approach

### 1. Convert dates into day numbers

Comparing dates becomes easier when each date is represented as its day number in the year.

For example:

- January 1 → day 1
- February 1 → day 32
- March 1 → day 60

To convert a date:

1. Extract the month and day using `substr()`.
2. Convert them into integers using `stoi()`.
3. Add the number of days in all preceding months to the current day.

### 2. Find the overlapping interval

The overlap starts at the later of the two arrival dates:

```cpp
start = max(arriveAlice, arriveBob);
```

The overlap ends at the earlier of the two departure dates:

```cpp
end = min(leaveAlice, leaveBob);
```

### 3. Calculate the number of days

If `start > end`, the stays do not overlap, so return `0`.

Otherwise, the number of overlapping days is:

```cpp
end - start + 1
```

We add `1` because both the starting and ending dates are inclusive.

# Complexity Analysis

Time Complexity: `O(1)`

Each date conversion processes at most 11 months. Since the number of months is fixed, the time complexity is constant.

Space Complexity: `O(1)`

The month-length array has a fixed size of 12, and only a constant number of variables are used.

# Solution

```cpp
class Solution {
public:
    int countDaysTogether(string arriveAlice, string leaveAlice,
                          string arriveBob, string leaveBob) {
        vector<int> daysInMonth = {
            31, 28, 31, 30, 31, 30,
            31, 31, 30, 31, 30, 31
        };

        auto toDay = [&](string date) {
            int month = stoi(date.substr(0, 2));
            int day = stoi(date.substr(3, 2));

            for (int i = 0; i < month - 1; i++) {
                day += daysInMonth[i];
            }

            return day;
        };

        int start = max(
            toDay(arriveAlice),
            toDay(arriveBob)
        );

        int end = min(
            toDay(leaveAlice),
            toDay(leaveBob)
        );

        return max(0, end - start + 1);
    }
};
```

# Key Insight

The overlapping interval begins at the later arrival date and ends at the earlier departure date.

The formula is:

\[
\text{Days} = \max(0,\ \min(L_A,L_B)-\max(A_A,A_B)+1)
\]

Here, \(A_A\) and \(A_B\) are the arrival dates, while \(L_A\) and \(L_B\) are the departure dates, all converted to day numbers.

# Notes

- Convert dates into day numbers to simplify comparisons.
- Use `max()` to find the later arrival date.
- Use `min()` to find the earlier departure date.
- Add `1` because the dates are inclusive.
- Use `max(0, ...)` to handle cases where the stays do not overlap.
