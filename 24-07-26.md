# 3550. Smallest Index With Digit Sum Equal to Index

Date Solved: September 24, 2026
Status: Solved

## Problem Statement

You are given an integer array nums.

Return the smallest index i such that the sum of the digits of nums[i] is equal to i.

If no such index exists, return -1.



## Examples

### Example 1

Input:
nums = [1,3,2]

Output:
2

Explanation:

For nums[2] = 2:

digit sum = 2

Since:

2 == index 2

the answer is 2.

### Example 2

Input:
nums = [1,10,11]

Output:
1

Explanation:

For nums[1] = 10:

digit sum = 1 + 0 = 1

Since:

1 == index 1

the answer is 1.

Although nums[2] = 11 also satisfies the condition:

1 + 1 = 2

index 1 is smaller.

### Example 3

Input:
nums = [1,2,3]

Output:
-1

Explanation:

No index has a digit sum equal to its index.



## Constraints

 1 <= nums.length <= 100
 0 <= nums[i] <= 1000



# Approach

We iterate through the array from left to right.

For every index i:

1. Calculate the digit sum of nums[i].
2. Compare the digit sum with i.
3. If they are equal, return i.

Because we check indices in increasing order, the first valid index is automatically the smallest.

### Calculating Digit Sum

For a number num:

 num % 10 gives the last digit.
 num /= 10 removes the last digit.

Continue until num becomes 0.

For example:

num = 123

123 % 10 = 3

12 % 10 = 2

1 % 10 = 1

Digit sum:

3 + 2 + 1 = 6



# Complexity

### Time Complexity

O(n * d)

where n is the array size and d is the maximum number of digits in an element.

### Space Complexity

O(1)

Only a few variables are used.



# Solution

cpp
class Solution {
public:
    int smallestIndex(vector<int>& nums) {
        for (int i = 0; i < nums.size(); i++) {
            int num = nums[i];
            int sum = 0;

            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }

            if (sum == i) {
                return i;
            }
        }

        return -1;
    }
};

# Key Insight

Since the array is checked from left to right, we can immediately return when the digit sum equals the current index.

This guarantees that the returned index is the smallest valid index.
