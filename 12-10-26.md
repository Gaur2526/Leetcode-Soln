# 2897. Apply Operations on Array to Maximize Sum of Squares

Date Solved: 12 October 2026

Status: Solved

## Problem Statement

You are given a 0-indexed integer array `nums` and a positive integer `k`.

You can perform the following operation any number of times:

Choose two distinct indices `i` and `j`, and simultaneously update:

- `nums[i] = nums[i] AND nums[j]`
- `nums[j] = nums[i] OR nums[j]`

Here, `AND` and `OR` represent bitwise AND and bitwise OR operations, respectively. Both updates use the original values of the two elements.

You must choose `k` elements from the final array and calculate the sum of their squares.

Return the maximum possible sum modulo `10^9 + 7`.

---

## Examples

Example 1:

Input: `nums = [2,6,5,8], k = 2`

Output: `261`

Explanation:

We can perform the following operations:

1. Choose indices `i = 0` and `j = 3`.
   - `2 AND 8 = 0`
   - `2 OR 8 = 10`
   - Array becomes `[0,6,5,10]`.

2. Choose indices `i = 2` and `j = 3`.
   - `5 AND 10 = 0`
   - `5 OR 10 = 15`
   - Array becomes `[0,6,0,15]`.

Choose `15` and `6`.

Sum of squares:

`15² + 6² = 225 + 36 = 261`

Example 2:

Input: `nums = [4,5,4,7], k = 3`

Output: `90`

Explanation:

We can choose `7`, `5`, and `4` without performing any operations.

Sum of squares:

`7² + 5² + 4² = 49 + 25 + 16 = 90`

---

## Constraints

- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`

---

# Approach: Greedy + Bit Manipulation

The main observation is that the operation preserves the total number of set bits at every bit position across the entire array.

For example:

`2 = 0010`
`8 = 1000`

After applying the operation:

`2 AND 8 = 0000`
`2 OR 8  = 1010`

The set bits are redistributed, but no set bits are lost from the array as a whole.

To maximize the sum of squares, we want to create numbers with as many high-value bits as possible.

Steps:

1. Create an array `bits` of size `31` to count set bits at each position.
2. Traverse every number in `nums`.
3. For each bit position from `0` to `30`, increment its count if that bit is set.
4. Construct `k` numbers greedily.
5. For each number, traverse the bit positions from `30` down to `0`.
6. If a bit's count is greater than zero:
   - Set that bit in the current number.
   - Decrease the corresponding bit count by one.
7. Add the square of the constructed number to the answer, taking the modulo after each addition.
8. Return the final answer.

Why does this work?

For nonnegative numbers, concentrating available set bits into the same number increases the sum of squares. Therefore, each constructed number receives every bit position that still has available occurrences, and each occurrence can be used only once.

---

# Complexity Analysis

Time Complexity: `O(31 * n + 31 * k)`

- Counting the bits takes `O(31 * n)`.
- Constructing `k` numbers takes `O(31 * k)`.
- Since `31` is constant, the overall complexity is `O(n + k)`.

Space Complexity: `O(1)`

The bit-count array always contains exactly `31` elements, regardless of the input size.

---

# Solution

    class Solution {
    public:
        int maxSum(vector<int>& nums, int k) {
            const long long MOD = 1e9 + 7;
            vector<int> bits(31, 0);

            for (int num : nums) {
                for (int b = 0; b < 31; b++) {
                    if (num & (1LL << b)) {
                        bits[b]++;
                    }
                }
            }

            long long ans = 0;

            for (int i = 0; i < k; i++) {
                long long num = 0;

                for (int b = 30; b >= 0; b--) {
                    if (bits[b] > 0) {
                        num |= (1LL << b);
                        bits[b]--;
                    }
                }

                ans = (ans + num * num % MOD) % MOD;
            }

            return ans;
        }
    };

# Dry Run

Input: `nums = [2,6,5,8], k = 2`

Binary representations:

- `2 = 0010`
- `6 = 0110`
- `5 = 0101`
- `8 = 1000`

Count the set bits:

| Bit Position | Set-Bit Count |
|---|---:|
| 3 | 1 |
| 2 | 2 |
| 1 | 2 |
| 0 | 1 |

Construct the first number:

- Bit 3 is available: set it.
- Bit 2 is available: set it.
- Bit 1 is available: set it.
- Bit 0 is available: set it.

First number:

`1111` in binary = `15`

Remaining counts:

- Bit 3: `0`
- Bit 2: `1`
- Bit 1: `1`
- Bit 0: `0`

Construct the second number:

- Bit 2 is available: set it.
- Bit 1 is available: set it.

Second number:

`0110` in binary = `6`

Calculate the sum:

`15² + 6² = 225 + 36 = 261`

Final Output: `261`

# Key Insight

The operation redistributes set bits without changing how many times each bit position occurs across the array.

To maximize the sum of squares, construct each of the `k` numbers by using every bit position that still has an available set bit.

This greedy strategy concentrates available bits into larger numbers, maximizing the sum of squares.

---

# Notes

- Use bit counting to avoid simulating the operations.
- Since `nums[i] <= 10^9`, bit positions `0` through `30` are sufficient.
- Use `1LL << b` to perform bit shifts using a 64-bit integer.
- Use `long long` for the constructed number and its square to avoid overflow.
- Apply modulo `10^9 + 7` while accumulating the answer.
- The solution runs in `O(n + k)` time and uses `O(1)` extra space.
