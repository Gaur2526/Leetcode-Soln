# 940. Distinct Subsequences II

Date solved: 2026-09-07  Status: ✅ Accepted

## Problem

````
```

Given a string s, return the number of distinct non-empty subsequences
of s.

Since the answer may be very large, return it modulo 10^9 + 7.

A subsequence of a string is a new string that is formed from the
original string by deleting some (can be none) of the characters
without disturbing the relative order of the remaining characters.

```
````

## Examples

````
```

Example 1

    Input

    s = "abc"

    Output

    7

    Explanation

    The 7 distinct subsequences are:

    "a", "b", "c", "ab", "ac", "bc", and "abc".



Example 2

    Input

    s = "aba"

    Output

    6

    Explanation

    The 6 distinct subsequences are:

    "a", "b", "ab", "aa", "ba", and "aba".



Example 3

    Input

    s = "aaa"

    Output

    3

    Explanation

    The 3 distinct subsequences are:

    "a", "aa", and "aaa".

```
````

## Constraints

````
```

1 <= s.length <= 2000

s consists of lowercase English letters.

```
````

## Approach

````
```

The important observation is that when we process a new character,
every existing distinct subsequence can either:

    1. Skip the current character.

    2. Append the current character.

Therefore, if there are dp distinct subsequences before processing
the current character, we would normally get:

    newDp = 2 * dp

However, this can create duplicate subsequences when the current
character has already appeared before.

For example:

    s = "aba"

After processing "ab", the distinct subsequences are:

    "", "a", "b", "ab"

When we process the second 'a', appending 'a' to existing
subsequences creates:

    "a", "aa", "ba", "aba"

The subsequence "a" was already present, so we need to remove
the duplicates created by the previous occurrence of 'a'.

To handle this efficiently, we maintain:

    last[c] = number of distinct subsequences before the previous
              occurrence of character c was processed.

Initially:

    dp = 1

because the empty subsequence is the only subsequence.

For every character c:

    newDp = 2 * dp - last[c]

The subtraction removes the duplicate subsequences that were
already generated when the previous occurrence of c was processed.

After calculating newDp:

    last[c] = dp

    dp = newDp

We use modulo 10^9 + 7 to prevent the values from becoming too large.

At the end, dp contains the empty subsequence as well.

Therefore, we return:

    dp - 1

to exclude the empty subsequence.

Example:

    s = "aaa"

Initially:

    dp = 1

Process first 'a':

    newDp = 2 * 1 - 0
          = 2

Distinct subsequences:

    "", "a"



Process second 'a':

    newDp = 2 * 2 - 1
          = 3

Distinct subsequences:

    "", "a", "aa"



Process third 'a':

    newDp = 2 * 3 - 2
          = 4

Distinct subsequences:

    "", "a", "aa", "aaa"

Finally:

    answer = 4 - 1
           = 3

```
````

## Complexity

````
```

Time: O(n)

Space: O(26)

where:

    n = s.length()

Since s consists only of lowercase English letters, we only need
an array of size 26 to store the last values.

```
````

## Solution

````
```

class Solution {

public:

    int distinctSubseqII(string s) {

        const long long MOD = 1e9 + 7;

        // dp = number of distinct subsequences
        // including the empty subsequence

        long long dp = 1;

        // last[c] stores the dp value before
        // the previous occurrence of character c

        vector<long long> last(26, 0);

        for (char c : s) {

            int idx = c - 'a';

            // Double the existing subsequences and
            // remove duplicates caused by this character

            long long newDp =
                (2 * dp - last[idx] + MOD) % MOD;

            // Store the old dp value for future
            // occurrences of this character

            last[idx] = dp;

            dp = newDp;

        }

        // Remove the empty subsequence

        return (dp - 1 + MOD) % MOD;

    }

};

```
````

## Notes

````
```

Key insight:

    Every new character can be appended to every existing
    subsequence.

Therefore:

    newDp = 2 * dp

But if the character appeared before, some of the newly generated
subsequences are duplicates.

We remove those duplicates using:

    newDp = 2 * dp - last[c]

The array:

    last[26]

stores the required previous state for each lowercase character.

Important:

    dp includes the empty subsequence.

Therefore, after processing the complete string:

    answer = dp - 1

because the problem asks for non-empty subsequences only.

Example:

    s = "abc"

There are no repeated characters, so the number of subsequences
simply doubles at every step:

    Initially:

        dp = 1

    After 'a':

        dp = 2

    After 'b':

        dp = 4

    After 'c':

        dp = 8

Removing the empty subsequence:

    answer = 8 - 1
           = 7



Example:

    s = "aaa"

Repeated characters create duplicates, so we cannot simply double
the number of subsequences.

    After first 'a':

        dp = 2

    After second 'a':

        dp = 3

    After third 'a':

        dp = 4

Removing the empty subsequence:

    answer = 3

The three non-empty distinct subsequences are:

    "a", "aa", "aaa"



The main trick is:

    dp = 1

    For every character c:

        newDp = 2 * dp - last[c]

        last[c] = dp

        dp = newDp

    Return:

        dp - 1

Since the answer can be very large, all calculations are performed
modulo:

    10^9 + 7

Therefore:

    Time -> O(n)

    Space -> O(26)

```
````
