# 678. Valid Parenthesis String

Date Solved: October 4, 2026

Status: Solved

## Problem Statement

Given a string \`s\` containing three types of characters:

\- \`(\`

\- \`)\`

\- \`*\`

Return \`true\` if the string is valid.

The rules are:

\- Every \`(\` must have a corresponding \`)\`.

\- Every \`)\` must have a corresponding \`(\`.

\- Opening parentheses must come before their corresponding closing parentheses.

\- \`*\` can be treated as \`(\`, \`)\`, or an empty string.

---

## Examples

### Example 1

Input:

s = "()"

Output:

true

### Example 2

Input:

s = "(*)"

Output:

true

Explanation:

The \`*\` can be treated as an empty string.

So the string becomes:

\`()\`

### Example 3

Input:

s = "(*))"

Output:

true

Explanation:

The \`*\` can be treated as an opening parenthesis.

So the string becomes:

\`(())\`

### Example 4

Input:

s = "("

Output:

false

---

## Constraints

\- \`1 <= s.length <= 100\`

\- \`s[i]\` is \`(\`, \`)\`, or \`*\`.

---

# Approach

We use a greedy approach by maintaining a range of possible unmatched opening parentheses.

Instead of deciding immediately what every \`*\` represents, we keep two values:

\`low\` → minimum possible number of unmatched \`(\`.

\`high\` → maximum possible number of unmatched \`(\`.

This allows us to represent all possible interpretations of \`*\` at once.

### Step 1: Handle Opening Parenthesis

For \`(\`:

\`low++\`

\`high++\`

An opening parenthesis definitely increases the number of unmatched opening parentheses.

### Step 2: Handle Closing Parenthesis

For \`)\`:

\`low--\`

\`high--\`

A closing parenthesis must match an opening parenthesis.

If \`high < 0\`, there are more closing parentheses than possible opening parentheses.

Therefore, the string cannot be valid.

### Step 3: Handle Asterisk

For \`*\`, there are three possibilities:

\`*\` can become \`(\`

\`*\` can become \`)\`

\`*\` can become empty.

To represent the range:

For the minimum:

Treat \`*\` as \`)\`:

\`low--\`

For the maximum:

Treat \`*\` as \`(\`:

\`high++\`

So:

\`low--\`

\`high++\`

### Step 4: Prevent Negative Low

If \`low < 0\`, set:

\`low = 0\`

Why?

Because if the minimum possible unmatched opening count becomes negative, we can simply choose a different interpretation of previous \`*\` characters.

We only need to keep the minimum possible value as 0.

### Step 5: Final Check

At the end:

\`low == 0\`

means there exists at least one interpretation of all the \`*\` characters that produces a valid parentheses string.

If \`low > 0\`, some opening parentheses remain unmatched.

Therefore:

\`return low == 0\`

---

# Complexity

### Time Complexity

O(n)

We process every character exactly once.

### Space Complexity

O(1)

Only two integer variables are used.

---

# Solution

cpp

class Solution {

public:

    bool checkValidString(string s) {

        int low = 0;

        int high = 0;

        for (char ch : s) {

            if (ch == '(') {

                low++;

                high++;

            }

            else if (ch == ')') {

                low--;

                high--;

            }

            else {

                // '*' can be ')' or '('

                low--;

                high++;

            }

            // Even the maximum possible balance is negative

            if (high < 0)

                return false;

            // Minimum balance cannot be negative

            low = max(low, 0);

        }

        return low == 0;

    }

};

# Dry Run

Consider:

s = "(*))"

Initially:

\`low = 0\`

\`high = 0\`

### Character 1: \`(\`

\`low = 1\`

\`high = 1\`

Possible unmatched opening count:

[1, 1]

### Character 2: \`*\`

\`*\` can be \`)\` or \`(\`.

\`low = 0\`

\`high = 2\`

Possible unmatched opening count:

[0, 2]

### Character 3: \`)\`

\`low = -1\`

\`high = 1\`

Since \`low\` cannot be negative:

\`low = 0\`

Range:

[0, 1]

### Character 4: \`)\`

\`low = -1\`

\`high = 0\`

Again:

\`low = 0\`

Final range:

[0, 0]

Therefore:

\`low == 0\`

Answer:

true

One valid interpretation is:

\`(*))\`

where \`*\` is treated as \`(\`.

This gives:

\`(())\`

---

# Key Insight

The important idea is that we do not need to decide what each \`*\` represents immediately.

Instead, maintain a range:

\`[low, high]\`

representing all possible numbers of unmatched opening parentheses.

For \`*\`:

\- Minimum balance assumes \`*\` is \`)\`.

\- Maximum balance assumes \`*\` is \`(\`.

If the maximum balance ever becomes negative, the string cannot be valid.

At the end, if the minimum balance is zero, at least one valid interpretation exists.

---

# Notes

 Use a greedy range instead of backtracking.

 \`low\` represents the minimum possible unmatched opening parentheses.

 \`high\` represents the maximum possible unmatched opening parentheses.

 \`(\` increases both values.

 \`)\` decreases both values.

 \`*\` decreases \`low\` and increases \`high\`.

 Never allow \`low\` to remain negative.

 If \`high < 0\`, immediately return \`false\`.

 At the end, return \`low == 0\`.

 The solution avoids trying all possible interpretations of \`*\`.

 Time complexity is O(n).

 Space complexity is O(1).
