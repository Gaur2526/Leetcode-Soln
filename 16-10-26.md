# 2916. Subarrays Distinct Element Sum of Squares II

Date Solved: 16 October 2026

Status: Solved

## Problem Statement

You are given a 0-indexed integer array `nums`.

The distinct count of a subarray is the number of unique elements present in that subarray.

A subarray is a contiguous, non-empty sequence of elements within an array.

Return the sum of the squares of the distinct counts of all possible subarrays of `nums`, modulo `10^9 + 7`.

---

## Examples

Example 1:

Input: `nums = [1,2,1]`

Output: `15`

Explanation:

The possible subarrays are:

- `[1]` → 1 distinct element → `1² = 1`
- `[2]` → 1 distinct element → `1² = 1`
- `[1]` → 1 distinct element → `1² = 1`
- `[1,2]` → 2 distinct elements → `2² = 4`
- `[2,1]` → 2 distinct elements → `2² = 4`
- `[1,2,1]` → 2 distinct elements → `2² = 4`

Total:

`1 + 1 + 1 + 4 + 4 + 4 = 15`

Example 2:

Input: `nums = [2,2]`

Output: `3`

Explanation:

The possible subarrays are:

- `[2]` → 1 distinct element → `1² = 1`
- `[2]` → 1 distinct element → `1² = 1`
- `[2,2]` → 1 distinct element → `1² = 1`

Total:

`1 + 1 + 1 = 3`

---

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

---

# Approach: Segment Tree + Lazy Propagation

The brute-force approach examines every subarray and takes `O(n²)` time, which is too slow for `n = 10^5`.

We can solve the problem in `O(n log n)` using a lazy segment tree.

Key idea:

Process the array from left to right. At every index `i`, maintain the distinct counts of all subarrays ending at `i`.

Let `prev` be the previous occurrence index of `nums[i]`. If the value has never appeared before, set `prev = -1`.

When we append `nums[i]` to a subarray:

- If its starting index is at most `prev`, the element already exists in that subarray, so the distinct count does not change.
- If its starting index is greater than `prev`, the element is new to that subarray, so the distinct count increases by `1`.

Therefore, we perform a range increment on:

`[prev + 1, i]`

What does the segment tree store?

For each segment, maintain:

- `sum`: sum of the distinct counts.
- `sumSq`: sum of the squares of the distinct counts.
- `lazy`: pending increment that must be applied to the segment's children.

When every distinct count in a segment increases by `x`, we use:

`(d + x)² = d² + 2xd + x²`

For a segment containing `len` starting positions:

`newSum = oldSum + x * len`

`newSumSq = oldSumSq + 2 * x * oldSum + x² * len`

All calculations are performed modulo `10^9 + 7`.

After processing each index, the root's `sumSq` represents the sum of squared distinct counts for all subarrays ending at that index.

Add this value to the final answer.

Steps:

1. Initialize a lazy segment tree with `n` positions.
2. Initialize an array `last` to `-1`, recording the last occurrence of each value.
3. For every index `i`, find `prev = last[nums[i]]`.
4. Increment the segment tree range `[prev + 1, i]` by `1`.
5. Update `last[nums[i]] = i`.
6. Add the root's `sumSq` to the answer modulo `10^9 + 7`.
7. Return the final answer.

---

# Complexity Analysis

Time Complexity: `O(n log n)`

Each array element triggers one range update, which takes `O(log n)` time.

Space Complexity: `O(n)`

The segment tree requires `O(n)` space. The last-occurrence array uses additional space proportional to the maximum value in `nums`.

# Solution

    class Solution {
        static const int MOD = 1e9 + 7;

        struct Node {
            long long sum = 0;
            long long sumSq = 0;
            long long lazy = 0;
        };

        vector<Node> tree;
        int n;

        void apply(int node, int l, int r, long long val) {
            long long len = r - l + 1;

            tree[node].sumSq =
                (tree[node].sumSq
                 + 2 * val % MOD * tree[node].sum % MOD
                 + val * val % MOD * len % MOD) % MOD;

            tree[node].sum =
                (tree[node].sum + val * len) % MOD;

            tree[node].lazy =
                (tree[node].lazy + val) % MOD;
        }

        void push(int node, int l, int r) {
            if (tree[node].lazy == 0 || l == r)
                return;

            int mid = l + (r - l) / 2;
            long long val = tree[node].lazy;

            apply(node * 2, l, mid, val);
            apply(node * 2 + 1, mid + 1, r, val);

            tree[node].lazy = 0;
        }

        void update(int node, int l, int r,
                    int ql, int qr, long long val) {
            if (ql > r || qr < l)
                return;

            if (ql <= l && r <= qr) {
                apply(node, l, r, val);
                return;
            }

            push(node, l, r);

            int mid = l + (r - l) / 2;

            update(node * 2, l, mid, ql, qr, val);
            update(node * 2 + 1, mid + 1, r, ql, qr, val);

            tree[node].sum =
                (tree[node * 2].sum
                 + tree[node * 2 + 1].sum) % MOD;

            tree[node].sumSq =
                (tree[node * 2].sumSq
                 + tree[node * 2 + 1].sumSq) % MOD;
        }

    public:
        int sumCounts(vector<int>& nums) {
            n = nums.size();
            tree.assign(4 * n, Node());

            vector<int> last(100001, -1);
            long long ans = 0;

            for (int i = 0; i < n; i++) {
                int prev = last[nums[i]];

                update(1, 0, n - 1, prev + 1, i, 1);

                last[nums[i]] = i;

                ans = (ans + tree[1].sumSq) % MOD;
            }

            return ans;
        }
    };

# Dry Run

Input: `nums = [1,2,1]`

Initially:

- `last[1] = -1`
- `last[2] = -1`
- `ans = 0`

Iteration 1: `i = 0`, `nums[i] = 1`

Previous occurrence:

`prev = -1`

Update range:

`[prev + 1, i] = [0,0]`

The distinct count for subarray `[1]` becomes `1`.

Root's `sumSq`:

`1² = 1`

Running answer:

`ans = 1`

Update `last[1] = 0`.

Iteration 2: `i = 1`, `nums[i] = 2`

Previous occurrence:

`prev = -1`

Update range:

`[0,1]`

The distinct counts become:

- Starting at index `0`: `[1,2]` → 2 distinct elements.
- Starting at index `1`: `[2]` → 1 distinct element.

Root's `sumSq`:

`2² + 1² = 5`

Running answer:

`ans = 1 + 5 = 6`

Update `last[2] = 1`.

Iteration 3: `i = 2`, `nums[i] = 1`

Previous occurrence:

`prev = 0`

Update range:

`[1,2]`

The distinct counts become:

- Starting at index `0`: `[1,2,1]` → 2 distinct elements.
- Starting at index `1`: `[2,1]` → 2 distinct elements.
- Starting at index `2`: `[1]` → 1 distinct element.

Root's `sumSq`:

`2² + 2² + 1² = 9`

Final answer:

`ans = 6 + 9 = 15`

Final Output: `15`

---

# Key Insight

When extending a subarray to the right, its distinct count increases only if the newly added value has not appeared inside that subarray already.

The previous occurrence of the value identifies exactly which starting positions need an increment.

A lazy segment tree maintains both the sum and the sum of squares of the distinct counts, allowing all these increments to be processed efficiently.

---

# Notes

- Brute force takes `O(n²)` time and is unsuitable for the maximum constraint.
- The range update is `[prev + 1, i]`, not `[prev, i]`.
- The segment tree tracks subarrays by their starting indices for the current right endpoint.
- `sumSq` at the root gives the contribution of all subarrays ending at the current index.
- Lazy propagation avoids updating every individual starting position.
- Apply modulo `10^9 + 7` throughout the calculations.
- The solution runs in `O(n log n)` time.
