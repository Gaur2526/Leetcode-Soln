# 32. Longest Valid Parentheses

Date Solved: October 3, 2026

Status: Solved

## Problem Statement

Given a string containing only \`(\` and \`)\`, return the length of the longest valid (well-formed) parentheses substring.

A valid parentheses substring must have correctly matched opening and closing parentheses.

---

## Examples

### Example 1

Input:

s = "(()"

Output:

2

Explanation:

The longest valid parentheses substring is:

\`()\`

### Example 2

Input:

s = ")()())"

Output:

4

Explanation:

The longest valid parentheses substring is:

\`()()\`

### Example 3

Input:

s = ""

Output:

0

---

## Constraints

\- \`0 <= s.length <= 3 * 10^4\`

\- \`s[i]\` is either \`(\` or \`)\`.

---

# Approach

We use a stack to store indices of unmatched parentheses.

The main idea is to use indices to calculate the length of every valid substring.

We initially push \`-1\` into the stack.

This acts as a boundary before the beginning of the string.

### Step 1: Handle Opening Parenthesis

When we encounter \`(\`, push its index into the stack.

This index represents an unmatched opening parenthesis.

For example:

\`(()\`

After processing the first two characters:

Stack:

\`[-1, 0, 1]\`

### Step 2: Handle Closing Parenthesis

When we encounter \`)\`, we first pop the top element.

This attempts to match the closing parenthesis with the most recent unmatched opening parenthesis.

If the stack becomes empty after popping, there is no valid starting boundary.

So we push the current index as the new boundary.

### Step 3: Calculate Valid Length

If the stack is not empty after popping, the top of the stack represents the index before the current valid substring.

Therefore:

\`length = i - st.top()\`

Update the answer using:

\`ans = max(ans, i - st.top())\`

### Step 4: Why \`-1\` Is Important

Consider:

\`()()\`

Initially:

Stack:

\`[-1]\`

At index 1, after processing \`()\`:

\`1 - (-1) = 2\`

So the valid substring length is correctly calculated as 2.

Without \`-1\`, we would not have the correct boundary for a valid substring starting from index 0.

---

# Complexity

### Time Complexity

O(n)

We process every character exactly once.

### Space Complexity

O(n)

In the worst case, all characters can be opening parentheses and stored in the stack.

---

# Solution

cpp

class Solution {

public:

    int longestValidParentheses(string s) {

        stack<int> st;

        st.push(-1);

        int ans = 0;

        for (int i = 0; i < s.size(); i++) {

            if (s[i] == '(') {

                st.push(i);

            } 
            else {

                st.pop();

                if (st.empty()) {

                    st.push(i);

                } 
                else {

                    ans = max(ans, i - st.top());

                }

            }

        }

        return ans;

    }

};

# Key Insight

The stack stores the index of the last unmatched opening parenthesis or the boundary before the current valid substring.

Whenever we successfully match a closing parenthesis, the top of the stack gives us the boundary from which the current valid substring starts.

Therefore:

\`current length = current index - stack top\`

The initial \`-1\` acts as a boundary for valid substrings that start at index 0.

---

# Notes

 Use a stack of indices rather than characters.

 Initialize the stack with \`-1\`.

 Push the index of every opening parenthesis.

 For a closing parenthesis, first pop the stack.

 If the stack becomes empty, push the current index as a new boundary.

 Otherwise, calculate the valid length using \`i - st.top()\`.

 Keep track of the maximum length.

 The solution processes the string only once.

 Time complexity is O(n).

 Space complexity is O(n).
