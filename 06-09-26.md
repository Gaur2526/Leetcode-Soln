# 115. Distinct Subsequences

Date solved: 2026-09-06  Status: ✅ Accepted

## Problem

    ```

    Given two strings s and t, return the number of distinct subsequences
    of s which equals t.

    The test cases are generated so that the answer fits on a 32-bit
    signed integer.

    ```

## Examples

    ```

    Example 1

        Input

        s = "rabbbit"
        t = "rabbit"

        Output

        3

        Explanation

        There are 3 distinct ways you can generate "rabbit" from "rabbbit".


    Example 2

        Input

        s = "babgbag"
        t = "bag"

        Output

        5

        Explanation

        There are 5 distinct ways you can generate "bag" from "babgbag".

    ```

## Constraints

    ```

    1 <= s.length, t.length <= 1000

    s and t consist of English letters.

    ```

## Approach

    ```

    The important observation is that for every character in s, we have
    two choices when it matches the current character in t:

        1. Use the character from s.
        2. Skip the character from s.

    We use dynamic programming to count the number of ways.

    Let:

        dp[j] = number of ways to form the first j characters of t
                using the characters of s processed so far.

    Initially:

        dp[0] = 1

    because there is exactly one way to form an empty string.

    For every character s[i - 1], we traverse t from right to left.

    If:

        s[i - 1] == t[j - 1]

    then we can either:

        Skip s[i - 1]
            -> dp[j]

        Use s[i - 1]
            -> dp[j - 1]

    Therefore:

        dp[j] = dp[j] + dp[j - 1]

    We iterate j backwards so that dp[j - 1] still represents the value
    from the previous iteration.

    Since the final answer is guaranteed to fit in a 32-bit signed integer,
    we also need to prevent intermediate integer overflow.

    If:

        dp[j - 1] > INT_MAX - dp[j]

    then adding the two values would exceed INT_MAX.

    In that case, we store INT_MAX instead.

    This prevents signed integer overflow while keeping the final answer
    within the required 32-bit range.

    ```

## Complexity

    ```

    Time: O(n * m)

    Space: O(m)

    where:

        n = s.length()
        m = t.length()

    ```

## Solution

    ```

    class Solution {
    public:
        int numDistinct(string s, string t) {

            int n = s.size();
            int m = t.size();

            vector<int> dp(m + 1, 0);

            // There is one way to form an empty string
            dp[0] = 1;

            for (int i = 1; i <= n; i++) {

                // Traverse backwards so dp[j - 1]
                // still represents the previous state
                for (int j = m; j >= 1; j--) {

                    if (s[i - 1] == t[j - 1]) {

                        // Prevent integer overflow
                        if (dp[j - 1] > INT_MAX - dp[j]) {
                            dp[j] = INT_MAX;
                        } else {
                            dp[j] += dp[j - 1];
                        }
                    }
                }
            }

            return dp[m];
        }
    };

    ```

## Notes

    ```

    Key insight:

        We need to count all different ways to form t from s while
        maintaining the relative order of characters.

    For every matching character:

        s[i - 1] == t[j - 1]

    we have two choices:

        1. Skip the current character of s.

        2. Use the current character of s to match t[j - 1].

    Therefore:

        dp[j] += dp[j - 1]

    The DP array is traversed from right to left.

    This is important because dp[j - 1] must still contain the value from
    the previous iteration.

    If we traversed from left to right, dp[j - 1] could already have been
    updated using the current character of s, which could cause the same
    character to be used more than once.

    Example:

        s = "rabbbit"
        t = "rabbit"

    The extra 'b' in s creates multiple possible subsequences that can
    generate "rabbit".

    The DP counts all these valid choices while preserving the order
    of characters.

    The main trick is:

        dp[0] = 1

        Compare characters of s and t.

        If they match:

            dp[j] += dp[j - 1]

        Traverse t from right to left.

        Prevent integer overflow using INT_MAX.

    Therefore:

        Time -> O(n * m)

        Space -> O(m)

    ```
