# 3524. Find X Value of Array I

Date Solved: September 21, 2026
Status: Solved

## Problem Statement

You are given an array of positive integers nums and a positive integer k.

You can perform an operation once where you remove any non-overlapping prefix and suffix from nums, such that nums remains non-empty.

The remaining elements form a contiguous non-empty subarray.

For every possible remainder x from 0 to k - 1, count the number of ways to perform the operation such that the product of the remaining elements has remainder x when divided by k.

Return an array result of size k, where result[x] represents the number of ways whose product has remainder x.

---

## Examples

### Example 1

Input:
nums = [1,2,3,4,5], k = 3

Output:
[9,2,4]

### Example 2

Input:
nums = [1,2,4,8,16,32], k = 4

Output:
[18,1,2,0]

### Example 3

Input:
nums = [1,1,2,1,1], k = 2

Output:
[9,6]

---

## Constraints

 1 <= nums[i] <= 10^9
 1 <= nums.length <= 10^5
 1 <= k <= 5

---

# Approach

After removing a prefix and suffix, the remaining elements are always a non-empty contiguous subarray.

Therefore, the problem is equivalent to counting the product remainder of every non-empty subarray.

Since k <= 5, we can maintain the number of subarrays for every possible remainder.

### Step 1: Define DP

Let:

dp[r] = number of subarrays ending at the previous index whose product has remainder r modulo k.

### Step 2: Start a new subarray

For every current number num, we can create a new subarray containing only that number.

Its remainder is:

num % k

So:

next[num % k]++

### Step 3: Extend previous subarrays

Every subarray counted in dp[r] can be extended by the current number.

The new product remainder becomes:

(r * (num % k)) % k

So:

next[newR] += dp[r]

### Step 4: Add to the answer

Every subarray ending at the current index represents one valid operation.

Therefore, after calculating next, add all its values to the final answer.

Then set:

dp = next

and continue with the next element.

---

# Complexity

### Time Complexity

O(n * k)

For every element, we iterate through all k possible remainders.

Since k <= 5, this is effectively O(n).

### Space Complexity

O(k)

We only store the remainder counts for the current and previous positions.

---

# Solution

cpp
class Solution {
public:
    vector<long long> resultArray(vector<int>& nums, int k) {
        vector<long long> ans(k, 0);
        vector<long long> dp(k, 0);

        for (int num : nums) {
            vector<long long> next(k, 0);

            // Start a new subarray
            next[num % k]++;

            // Extend previous subarrays
            for (int r = 0; r < k; r++) {
                int newR = (r * (num % k)) % k;
                next[newR] += dp[r];
            }

            dp = next;

            // Add all subarrays ending at current index
            for (int r = 0; r < k; r++) {
                ans[r] += dp[r];
            }
        }

        return ans;
    }
};

# Dry Run

Consider:

nums = [1,2,3]

k = 3

### Process 1

Start subarray:

[1]

Product:

1 % 3 = 1

So:

dp = [0,1,0]

Answer:

[0,1,0]

### Process 2

New subarray:

[2] → remainder 2

Extend:

[1,2] → product 2 → remainder 2

So:

dp = [0,0,2]

Answer becomes:

[0,1,2]

### Process 3

New subarray:

[3] → remainder 0

Extend:

[2,3] → product 6 → remainder 0

[1,2,3] → product 6 → remainder 0

So:

dp = [3,0,0]

Final answer:

[3,1,2]

---

# Key Insight

Removing a prefix and suffix leaves exactly one non-empty contiguous subarray.

So instead of thinking about prefix/suffix removal directly, we count all non-empty subarrays by their product remainder.

Because k is at most 5, keeping a DP count for every remainder is very small and efficient.

---

# Notes

 Every valid operation corresponds to exactly one non-empty contiguous subarray.
 dp[r] stores subarrays ending at the previous position.
 A new element can either start a new subarray or extend an existing one.
 Products are calculated modulo k to keep values small.
 Use long long for the answer because the number of subarrays can be large.
 Total number of non-empty subarrays can be up to n * (n + 1) / 2.
