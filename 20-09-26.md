# 3498. Reverse Degree of a String

Date Solved: September 20, 2026
Status: Solved

## Problem Statement

Given a string s, calculate its reverse degree.

The reverse degree is calculated as follows:

 For each character, multiply its position in the reversed alphabet ('a' = 26, 'b' = 25, ..., 'z' = 1) with its position in the string (1-indexed).
 Sum these products for all characters in the string.

Return the reverse degree of s.


## Examples

### Example 1

Input:
s = "abc"

Output:
148

Explanation:

 'a' → Reverse alphabet position = 26, String position = 1 → 26 * 1 = 26
 'b' → Reverse alphabet position = 25, String position = 2 → 25 * 2 = 50
 'c' → Reverse alphabet position = 24, String position = 3 → 24 * 3 = 72

Total:

26 + 50 + 72 = 148

### Example 2

Input:
s = "zaza"

Output:
160

Explanation:

 'z' → 1 * 1 = 1
 'a' → 26 * 2 = 52
 'z' → 1 * 3 = 3
 'a' → 26 * 4 = 104

Total:

1 + 52 + 3 + 104 = 160


## Constraints

 1 <= s.length <= 1000
 s contains only lowercase English letters.


# Approach

The key idea is to calculate the reverse alphabet position of each character and multiply it by its 1-indexed position in the string.

### Step 1: Find the reverse alphabet position

For a character s[i], its normal alphabet position is:

s[i] - 'a'

Since 'a' should have value 26 and 'z' should have value 1:

reversePos = 26 - (s[i] - 'a')

### Step 2: Find the position in the string

The loop index is 0-based, so the 1-indexed position is:

stringPos = i + 1

### Step 3: Add the product

For every character:

ans += reversePos * stringPos


# Complexity

### Time Complexity

O(n)

We iterate through the string once.

### Space Complexity

O(1)

Only a few integer variables are used.


# Solution

cpp
class Solution {
public:
    int reverseDegree(string s) {
        int ans = 0;

        for (int i = 0; i < s.size(); i++) {
            int reversePos = 26 - (s[i] - 'a');
            int stringPos = i + 1;

            ans += reversePos * stringPos;
        }

        return ans;
    }
};



# Dry Run

For:

s = "abc"

Character 1:

s[0] = 'a'

Reverse position:

26 - ('a' - 'a') = 26

String position:

0 + 1 = 1

Contribution:

26 * 1 = 26

Character 2:

s[1] = 'b'

Reverse position:

26 - ('b' - 'a') = 25

String position:

1 + 1 = 2

Contribution:

25 * 2 = 50

Character 3:

s[2] = 'c'

Reverse position:

26 - ('c' - 'a') = 24

String position:

2 + 1 = 3

Contribution:

24 * 3 = 72

Final answer:

26 + 50 + 72 = 148


# Key Insight

The reverse alphabet position can be calculated directly using:

26 - (s[i] - 'a')

Then multiply it by the 1-indexed position i + 1.

This allows us to solve the problem with a single pass through the string.


# Notes

 The alphabet position is reversed.
 'a' has reverse position 26.
 'z' has reverse position 1.
 String positions are 1-indexed.
 No extra data structure is required.
 The solution runs in O(n) time and O(1) space.
