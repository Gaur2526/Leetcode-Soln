# 1477. Find Two Non-overlapping Sub-arrays Each With Target Sum

Date Solved: September 17, 2026

Status: Solved

## Problem Statement

You are given an array of integers arr and an integer target.

You have to find two non-overlapping sub-arrays of arr each with a sum equal to target.

There can be multiple answers, so you have to find an answer where the sum of the lengths of the two sub-arrays is minimum.

Return the minimum sum of the lengths of the two required sub-arrays, or return -1 if you cannot find such two sub-arrays.

---

## Examples

### Example 1

Input:

arr = [3,2,2,4,3], target = 3

Output:

2

Explanation:

Only two sub-arrays have sum equal to 3:

[3] and [3]

Both have length 1, so the minimum sum of their lengths is:

1 + 1 = 2

### Example 2

Input:

arr = [7,3,4,7], target = 7

Output:

2

Explanation:

There are three sub-arrays with sum equal to 7:

[7], [3,4], and [7]

We choose the first and third sub-arrays because they are non-overlapping and their total length is:

1 + 1 = 2

### Example 3

Input:

arr = [4,3,2,6,2,3,4], target = 6

Output:

-1

Explanation:

There is only one sub-array with sum equal to 6.

Therefore, we cannot select two non-overlapping sub-arrays.

---

## Constraints

 1 <= arr.length <= 10^5

 1 <= arr[i] <= 1000

 1 <= target <= 10^8

---

# Approach

Since all elements of arr are positive, we can use a sliding window to find every sub-array whose sum is exactly target.

At the same time, we maintain the minimum length of a valid sub-array that has appeared before the current position.

The main idea is:

1. Use a sliding window to find a sub-array with sum equal to target.

2. Store the minimum length of any valid sub-array seen so far.

3. When we find a new valid sub-array, combine it with the best valid sub-array that ends before it.

4. Keep the minimum total length.

---

## Step 1: Sliding Window

Because every element is positive, if the current sum becomes greater than target, we can safely move the left pointer forward.

We maintain:

left

right

and:

sum

For every new right:

sum += arr[right]

If:

sum > target

we repeatedly remove elements from the left:

sum -= arr[left]

left++

Eventually:

 Either sum == target

 Or sum < target

When:

sum == target

we have found a valid sub-array:

[left, right]

Its length is:

right - left + 1

---

## Step 2: Store the Best Previous Sub-array

Define:

best[i]

as the minimum length of a valid sub-array with sum equal to target that ends at or before index i.

For example:

best[i]

contains the shortest valid sub-array found in:

arr[0...i]

If we find a new valid sub-array starting at left, then a previous sub-array can be combined with it only if it ends before left.

Therefore, we use:

best[left - 1]

This guarantees that the two sub-arrays are non-overlapping.

---

## Step 3: Combine Two Non-overlapping Sub-arrays

Suppose the current valid sub-array is:

[left, right]

and its length is:

right - left + 1

If:

left > 0

and:

best[left - 1] != INF

then there is a valid previous sub-array that ends before the current sub-array starts.

Therefore:

ans = min(ans, best[left - 1] + length)

This checks all possible combinations while keeping only the shortest previous sub-array.

---

## Step 4: Maintain the Minimum Length

Whenever we find a valid sub-array, update:

minLen = min(minLen, length)

Then:

best[right] = minLen

This means that at every index, best[right] represents the shortest valid sub-array found anywhere up to that index.

---

## Detailed Steps

1. Let n = arr.size().

2. Initialize an array best[n] with a large value INF.

3. Initialize:

   left = 0

   sum = 0

   minLen = INF

   ans = INF

4. Iterate right from 0 to n - 1.

5. Add the current element:

   sum += arr[right]

6. While:

   sum > target

   remove elements from the left:

   sum -= arr[left]

   left++

7. If:

   sum == target

   then we found a valid sub-array.

8. Calculate its length:

   len = right - left + 1

9. If left > 0 and a previous valid sub-array exists, update:

   ans = min(ans, len + best[left - 1])

10. Update the shortest valid sub-array seen so far:

   minLen = min(minLen, len)

11. Store:

   best[right] = minLen

12. After processing the entire array, return ans if it was updated; otherwise return -1.

---

# Complexity

Let n = arr.length.

## Time Complexity

Each element enters the sliding window once and leaves the sliding window at most once.

Therefore, the sliding window takes:

O(n)

The best array is also processed in constant time per index.

Therefore:

Time: O(n)

## Space Complexity

We use the best array of size n.

Therefore:

Space: O(n)

# Solution

cpp

class Solution {

public:

    int minSumOfLengths(vector<int>& arr, int target) {

        int n = arr.size();

        const int INF = 1e9;

        // best[i] = minimum length of a valid sub-array

        // ending at or before index i

        vector<int> best(n, INF);

        int left = 0;

        long long sum = 0;

        int ans = INF;

        int minLen = INF;

        for (int right = 0; right < n; right++) {

            sum += arr[right];

            // Shrink the window if the sum becomes too large

            while (sum > target) {

                sum -= arr[left++];

            }

            // Current window has sum equal to target

            if (sum == target) {

                int len = right - left + 1;

                // Combine with the best non-overlapping

                // sub-array that ends before 'left'

                if (left > 0 && best[left - 1] != INF) {

                    ans = min(ans, len + best[left - 1]);

                }

                // Update the shortest valid sub-array

                minLen = min(minLen, len);

            }

            // Store the best valid sub-array seen so far

            best[right] = minLen;

        }

        return ans == INF ? -1 : ans;

    }

};

# Key Insight

The key observation is that all elements are positive.

This allows us to use a sliding window because:

 If the current sum is too large, moving the left pointer forward always decreases the sum.

 If the current sum is equal to the target, we have found a valid sub-array.

The second important idea is to remember the shortest valid sub-array seen so far.

When we find a new valid sub-array starting at left, we only need the best sub-array that ends before left.

That is why we use:

best[left - 1]

The combination:

best[left - 1] + currentLength

automatically guarantees that the two sub-arrays do not overlap.

Therefore, the complete solution runs in:

O(n)

time.

# Notes

 The sliding window works because all elements are positive.

 best[i] stores the minimum length of a valid sub-array ending at or before index i.

 We use best[left - 1] to guarantee that the previous sub-array does not overlap with the current one.

 We only need the shortest previous sub-array because the goal is to minimize the total length.

 Each element is added to and removed from the sliding window at most once.

 The final answer is -1 if fewer than two non-overlapping sub-arrays with sum equal to target exist.
