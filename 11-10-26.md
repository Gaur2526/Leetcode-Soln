# 2778. Sum of Squares of Special Elements

Date Solved: 11 October 2026

Status: Solved

## Problem Statement

You are given a 1-indexed integer array `nums` of length `n`.

An element `nums[i]` is called special if its 1-based index `i` divides `n`, meaning `n % i == 0`.

Return the sum of the squares of all special elements.

---

## Examples

Example 1:

Input: `nums = [1,2,3,4]`

Output: `21`

Explanation:

The special elements are:
- `nums[1] = 1`, because `4 % 1 == 0`
- `nums[2] = 2`, because `4 % 2 == 0`
- `nums[4] = 4`, because `4 % 4 == 0`

Sum of squares:

`1² + 2² + 4² = 1 + 4 + 16 = 21`

Example 2:

Input: `nums = [2,7,1,19,18,3]`

Output: `63`

Explanation:

The special elements are:
- `nums[1] = 2`, because `6 % 1 == 0`
- `nums[2] = 7`, because `6 % 2 == 0`
- `nums[3] = 1`, because `6 % 3 == 0`
- `nums[6] = 3`, because `6 % 6 == 0`

Sum of squares:

`2² + 7² + 1² + 3² = 4 + 49 + 1 + 9 = 63`

---

## Constraints

- `1 <= nums.length == n <= 50`
- `1 <= nums[i] <= 50`

---

# Approach

1. Store the length of the array in `n`.
2. Initialize `sum = 0`.
3. Traverse the array using a 0-based index `i`.
4. Since the problem uses 1-based indexing, use `i + 1` to get the actual position.
5. Check whether `n % (i + 1) == 0`.
6. If the condition is true, add `nums[i] * nums[i]` to `sum`.
7. Return `sum` after processing all elements.

---

# Complexity Analysis

Time Complexity: `O(n)`

We traverse the array exactly once and perform a constant-time divisibility check for each element.

Space Complexity: `O(1)`

We use only a constant amount of additional space.

---

# Solution

    class Solution {
    public:
        int sumOfSquares(vector<int>& nums) {
            int n = nums.size();
            int sum = 0;

            for (int i = 0; i < n; i++) {
                if (n % (i + 1) == 0) {
                    sum += nums[i] * nums[i];
                }
            }

            return sum;
        }
    };

---

# Dry Run

Input: `nums = [1,2,3,4]`

Array length: `n = 4`

Initially: `sum = 0`

| Index `i` | Actual Position `i + 1` | Check | Action | Sum |
|---|---|---|---|---|
| 0 | 1 | `4 % 1 == 0` | Add `1 * 1` | 1 |
| 1 | 2 | `4 % 2 == 0` | Add `2 * 2` | 5 |
| 2 | 3 | `4 % 3 != 0` | Skip | 5 |
| 3 | 4 | `4 % 4 == 0` | Add `4 * 4` | 21 |

Final Output: `21`

---

# Key Insight

An element is special when its 1-based position is a divisor of the array length.

Since C++ arrays use 0-based indexing, the actual position is `i + 1`.

The condition is:

    n % (i + 1) == 0

If true, add the square of the element to the answer.

---

# Notes

- Remember the difference between 0-based and 1-based indexing.
- Use `i + 1` when checking whether the position divides `n`.
- There is no need to store the special elements separately.
- A single traversal is sufficient.
- The solution uses `O(n)` time and `O(1)` extra space.
