# 22. Generate Parentheses

Date Solved: October 2, 2026

Status: Solved

## Problem Statement

Given n pairs of parentheses, generate all combinations of well-formed parentheses.

A well-formed parentheses string must follow these rules:

 Every opening parenthesis must eventually be closed.

 At any point, the number of closing parentheses cannot be greater than the number of opening parentheses.

 The total number of opening and closing parentheses must each be exactly n.

---

## Examples

### Example 1

Input:

n = 3

Output:

["((()))","(()())","(())()","()(())","()()()"]

### Example 2

Input:

n = 1

Output:

["()"]

---

## Constraints

 1 <= n <= 8

---

# Approach

We use backtracking to generate all possible valid parentheses combinations.

We maintain two counters:

open → number of opening parentheses used.

close → number of closing parentheses used.

At every step, we have two possible choices.

### Step 1: Add Opening Parenthesis

We can add ( if:

open < n

This ensures that we never use more than n opening parentheses.

### Step 2: Add Closing Parenthesis

We can add ) only if:

close < open

This is the most important condition.

It ensures that we never close a parenthesis that has not been opened yet.

For example:

())

is invalid because after the second ), the number of closing parentheses becomes greater than the number of opening parentheses.

### Step 3: Complete a Combination

When:

open == n && close == n

we have used all parentheses.

The current string is valid, so we add it to the answer.

### Step 4: Backtracking

After exploring a choice, we remove the last character using:

current.pop_back()

This allows us to explore other possible combinations.

---

# Complexity

Let Cₙ be the nth Catalan number, which represents the number of valid parentheses combinations.

### Time Complexity

O(Cₙ × n)

There are Cₙ valid combinations, and each combination has length 2n.

### Space Complexity

O(Cₙ × n)

The output itself contains Cₙ strings of length 2n.

The recursion stack uses O(n) additional space.

---

# Solution

cpp

class Solution {

public:

    void backtrack(int n, int open, int close,

                   string& current, vector<string>& ans) {

        if (open == n && close == n) {

            ans.push_back(current);

            return;

        }

        if (open < n) {

            current.push_back('(');

            backtrack(n, open + 1, close, current, ans);

            current.pop_back();

        }

        if (close < open) {

            current.push_back(')');

            backtrack(n, open, close + 1, current, ans);

            current.pop_back();

        }

    }

    vector<string> generateParenthesis(int n) {

        vector<string> ans;

        string current;

        backtrack(n, 0, 0, current, ans);

        return ans;

    }

};

---

# Key Insight

The most important condition is:

close < open

We can only add a closing parenthesis when there is an unmatched opening parenthesis available.

Therefore, every generated string is guaranteed to remain potentially valid.

Backtracking explores all valid choices without generating invalid combinations unnecessarily.

# Notes

 Use backtracking to generate all valid combinations.

 open tracks the number of opening parentheses used.

 close tracks the number of closing parentheses used.

 Add ( while open < n.

 Add ) only while close < open.

 When open == n && close == n, add the string to the result.

 Use pop_back() to undo the previous choice.

 The number of valid combinations is the nth Catalan number.

 Time complexity is O(Cₙ × n).

 Space complexity is O(Cₙ × n) including the output.
