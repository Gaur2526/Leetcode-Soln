# 3644. Maximum K to Sort a Permutation

Date Solved: 23 October 2026

Status: Solved

## Problem Statement

You are given an integer array `nums` of length `n`, which is a permutation of the numbers in the range `[0, n - 1]`.

You may swap elements at indices `i` and `j` only if:

`nums[i] & nums[j] == k`

Here, `&` represents the bitwise AND operation, and `k` is a non-negative integer.

Return the maximum value of `k` such that the array can be sorted in non-decreasing order using any number of allowed swaps.

If the array is already sorted, return `0`.

---

## Examples

Example 1

Input:
```cpp
nums = [0, 3, 2, 1]
```

Output:
```cpp
1
```

Explanation:

Choose `k = 1`. We can swap `3` and `1` because:

`3 & 1 = 1`

The array becomes `[0, 1, 2, 3]`.

Example 2

Input:
```cpp
nums = [0, 1, 3, 2]
```

Output:
```cpp
2
```

Explanation:

Choose `k = 2`. We can swap `3` and `2` because:

`3 & 2 = 2`

The array becomes `[0, 1, 2, 3]`.

Example 3

Input:
```cpp
nums = [3, 2, 1, 0]
```

Output:
```cpp
0
```

Explanation:

Only `k = 0` allows the necessary swaps to sort the array.

## Constraints

- `1 <= n == nums.length <= 10^5`
- `0 <= nums[i] <= n - 1`
- `nums` is a permutation of integers from `0` to `n - 1`.

# Approach

### 1. Identify misplaced elements

In a sorted permutation, every element `i` must be at index `i`.

Therefore, if `nums[i] != i`, that element is misplaced and must participate in at least one swap.

### 2. Find the common set bits

For a swap to be allowed, both participating values must have all the set bits required by `k`.

Thus, every misplaced value must contain every set bit of `k`.

We can calculate the bitwise AND of all misplaced values:

```cpp
ans &= nums[i];
```

This retains only the bits shared by every misplaced element.

### 3. Handle an already sorted array

If no elements are misplaced, no swaps are needed. The problem specifically requires returning `0`.

# Complexity Analysis

Time Complexity: `O(n)`

We traverse the array once.

Space Complexity: `O(1)`

Only a constant number of variables are used.

# Solution

```cpp
class Solution {
public:
    int sortPermutation(vector<int>& nums) {
        int n = nums.size();
        int ans = (1 << 30) - 1;

        for (int i = 0; i < n; i++) {
            if (nums[i] != i) {
                ans &= nums[i];
            }
        }

        return ans == ((1 << 30) - 1) ? 0 : ans;
    }
};
```

# Dry Run

Consider:

```cpp
nums = [0, 3, 2, 1]
```

Initially:

```cpp
ans = (1 << 30) - 1
```

Step 1: `i = 0`

`nums[0] = 0`

Since `nums[0] == 0`, this element is already in its correct position.

No change to `ans`.

Step 2: `i = 1`

`nums[1] = 3`

Since `3 != 1`, the element is misplaced.

```cpp
ans = ans & 3;
```

The relevant bits are:

```text
3 = 011
```

So `ans` becomes `3`.

Step 3: `i = 2`

`nums[2] = 2`

Since `nums[2] == 2`, this element is already in its correct position.

No change to `ans`.

Step 4: `i = 3`

`nums[3] = 1`

Since `1 != 3`, the element is misplaced.

```cpp
ans = 3 & 1;
```

In binary:

```text
3 = 011
1 = 001
    ---
    001
```

Therefore:

```cpp
ans = 1;
```

Final output:

```cpp
1
```

# Key Insight

The maximum valid `k` is the bitwise AND of all misplaced elements.

Every misplaced element must be movable, and every set bit required by `k` must be present in all values that need to move. Taking their AND gives the largest candidate.

# Notes

- Correctly positioned elements do not need to participate in swaps.
- Bitwise AND keeps only the bits that are set in every operand.
- The algorithm runs in linear time and uses constant extra space.
- If all elements are already in their correct positions, return `0`.
