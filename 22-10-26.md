# 3942. Minimum Operations to Sort a Permutation

Date Solved: 22 October 2026

Status: Solved

## Problem Statement

You are given an integer array `nums` of length `n`, which is a permutation of integers from `0` to `n - 1`.

You can perform only these operations:

1. Reverse the entire array: Reverse the order of all elements.
2. Rotate Left by One: Move the first element to the end of the array and shift the remaining elements one position to the left.

Return the minimum number of operations required to sort the array in increasing order. If sorting is impossible using these operations, return `-1`.

---

## Examples

Example 1

Input:
```cpp
nums = [0, 2, 1]
```

Output:
```cpp
2
```

Explanation:

- Rotate left: `[2, 1, 0]`
- Reverse: `[0, 1, 2]`

Total operations = 2.

Example 2

Input:
```cpp
nums = [1, 0, 2]
```

Output:
```cpp
2
```

Explanation:

- Reverse: `[2, 0, 1]`
- Rotate left: `[0, 1, 2]`

Total operations = 2.

Example 3

Input:
```cpp
nums = [2, 0, 1, 3]
```

Output:
```cpp
-1
```

Explanation:

The array cannot be sorted using the allowed operations.

## Constraints

- `1 <= n == nums.length <= 10^5`
- `0 <= nums[i] <= n - 1`
- `nums` is a permutation of integers from `0` to `n - 1`.

# Approach

### 1. Check if the array is already sorted

If `nums` is already sorted, return `0`.

### 2. Check whether sorting is possible

The allowed operations can only rotate the original array or rotate its reversed version.

Therefore, the original array must follow one of these cyclic patterns:

- Cyclic ascending: Each element is the previous element plus one, wrapping around from `n - 1` to `0`.
- Cyclic descending: Each element is the previous element minus one, wrapping around from `0` to `n - 1`.

If neither pattern matches, return `-1`.

### 3. Represent each possible state

There are at most `2 * n` states:

- Orientation `0`: The original array.
- Orientation `1`: The reversed original array.
- Offset: The number of left rotations applied to that orientation.

The state is encoded as:

```cpp
state = orientation * n + offset;
```

### 4. Use BFS

Starting from state `0`, explore both possible operations:

- Rotate left: Increase the offset by one, wrapping around at `n`.
- Reverse: Switch orientation and change the offset to `(n - offset) % n`.

BFS explores states in increasing order of operation count, so the first sorted state reached gives the minimum number of operations.

# Complexity Analysis

Time Complexity: `O(n)`

There are at most `2 * n` states, and each state has two transitions. Each state is visited at most once.

Space Complexity: `O(n)`

The distance array, queue, and goal-state array require linear space.

# Solution

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums) {
        int n = nums.size();

        if (is_sorted(nums.begin(), nums.end())) {
            return 0;
        }

        bool ascending = true;
        bool descending = true;

        for (int i = 0; i < n; i++) {
            if (nums[i] != (nums[0] + i) % n) {
                ascending = false;
            }

            if (nums[i] != (nums[0] - i + n) % n) {
                descending = false;
            }
        }

        if (!ascending && !descending) {
            return -1;
        }

        int zeroPos = find(
            nums.begin(), nums.end(), 0
        ) - nums.begin();

        int totalStates = 2 * n;

        vector<int> dist(totalStates, -1);
        vector<bool> goal(totalStates, false);
        queue<int> q;

        // Original orientation.
        if (ascending) {
            goal[zeroPos] = true;
        }

        // Reversed orientation.
        if (descending) {
            int reversedZeroPos = n - 1 - zeroPos;
            goal[n + reversedZeroPos] = true;
        }

        dist[0] = 0;
        q.push(0);

        while (!q.empty()) {
            int state = q.front();
            q.pop();

            if (goal[state]) {
                return dist[state];
            }

            int orientation = state / n;
            int offset = state % n;

            // Operation 1: Rotate left by one.
            int rotated =
                orientation * n + (offset + 1) % n;

            if (dist[rotated] == -1) {
                dist[rotated] = dist[state] + 1;
                q.push(rotated);
            }

            // Operation 2: Reverse the entire array.
            int reversedOrientation = 1 - orientation;
            int reversedOffset = (n - offset) % n;

            int reversed =
                reversedOrientation * n + reversedOffset;

            if (dist[reversed] == -1) {
                dist[reversed] = dist[state] + 1;
                q.push(reversed);
            }
        }

        return -1;
    }
};
```

# Key Insight

Reversing and rotating an array cannot create arbitrary permutations. They preserve the circular order of elements, either in the original direction or the opposite direction.

Consequently, sorting is possible only when the array is a cyclic rotation of the sorted permutation or its reverse. BFS over the `2 * n` orientation-and-offset states finds the minimum number of operations.

# Notes

- Return `0` immediately if the array is already sorted.
- Return `-1` if neither cyclic pattern matches.
- BFS guarantees the minimum number of operations because every operation has equal cost.
- The algorithm runs in linear time and is suitable for `n <= 10^5`.
