# 1541. Minimum Insertions to Balance a Parentheses String

Date Solved: October 9, 2026

Status: Solved

## Problem Statement

Given a parentheses string \`s\` containing only \`(\` and \`)\`, return the minimum number of insertions needed to make the string balanced.

A balanced string follows these rules:

\- Every opening parenthesis \`(\` must have two consecutive closing parentheses \`))\` corresponding to it.

\- The opening parenthesis must appear before its corresponding two closing parentheses.

In other words, each \`(\` requires a matching \`))\`.

---

## Examples

### Example 1

Input:

s = "(()))"

Output:

1

Explanation:

The first opening parenthesis has only one matching closing parenthesis.

Insert one \`)\` to obtain:

\`(())))\`

### Example 2

Input:

s = "())"

Output:

0

Explanation:

The string is already balanced.

### Example 3

Input:

s = "))())("

Output:

3

Explanation:

\- Insert one \`(\` to match the first \`))\`.

\- Insert two \`)\` to match the last \`(\`.

Total insertions:

3

---

## Constraints

\- \`1 <= s.length <= 10^5\`

\- \`s\` consists of only \`(\` and \`)\`.

---

# Approach

We use a greedy approach with two variables:

\`open\` → number of unmatched opening parentheses.

\`ans\` → number of insertions required so far.

The key observation is that every opening parenthesis requires two consecutive closing parentheses.

We process the string from left to right.

### Step 1: Handle Opening Parenthesis

When we encounter \`(\`, increase the number of unmatched opening parentheses:

\`open++\`

Each unmatched opening parenthesis still needs two closing parentheses.

### Step 2: Handle Closing Parentheses

When we encounter \`)\`, we need to form a pair of consecutive closing parentheses.

If the next character is also \`)\`, we consume both characters.

Otherwise, we insert one missing \`)\`:

\`ans++\`

### Step 3: Match an Opening Parenthesis

After obtaining a closing pair \`))\`, check whether an unmatched opening parenthesis exists.

If:

\`open > 0\`

we match the pair with an opening parenthesis:

\`open--\`

Otherwise, the closing pair has no corresponding opening parenthesis.

We must insert one:

\`ans++\`

### Step 4: Handle Remaining Opening Parentheses

After processing the entire string, some opening parentheses may remain unmatched.

Each one requires two closing parentheses.

Therefore, the final answer is:

\`ans + 2 * open\`

---

# Complexity

### Time Complexity

O(n)

We traverse the string once. When two consecutive closing parentheses are found, we skip the second one.

### Space Complexity

O(1)

Only two integer variables are used.

---

# Solution

cpp

class Solution {

public:

    int minInsertions(string s) {

        int open = 0;

        int ans = 0;

        for (int i = 0; i < s.size(); i++) {

            if (s[i] == '(') {

                open++;

            } 
            else {

                // Consume a pair of closing parentheses

                if (i + 1 < s.size() && s[i + 1] == ')') {

                    i++;

                } 
                else {

                    // Insert the missing ')'

                    ans++;

                }

                // Match the closing pair with an opening parenthesis

                if (open > 0) {

                    open--;

                } 
                else {

                    // Insert a missing '('

                    ans++;

                }

            }

        }

        // Each unmatched '(' requires two ')'

        return ans + 2 * open;

    }

};

# Dry Run

Consider:

s = "))())("

Initially:

\`open = 0\`

\`ans = 0\`

### Step 1: First \`)\`

The next character is also \`)\`.

So we consume the pair:

\`))\`

No unmatched opening parenthesis exists.

Insert one \`(\`.

Now:

\`open = 0\`

\`ans = 1\`

### Step 2: Next \`(\`

Increase the unmatched opening count:

\`open = 1\`

\`ans = 1\`

### Step 3: Next \`)\`

The next character is also \`)\`.

Consume the pair:

\`))\`

An unmatched opening parenthesis exists, so match it:

\`open = 0\`

\`ans = 1\`

### Step 4: Final \`(\`

Increase the unmatched opening count:

\`open = 1\`

\`ans = 1\`

At the end, one opening parenthesis remains unmatched.

It requires two closing parentheses:

\`2 * open = 2\`

Final answer:

\`ans + 2 * open = 1 + 2 = 3\`

---

# Key Insight

Every \`(\` needs two consecutive \`)\` characters.

Whenever we encounter a closing parenthesis, we try to form a pair:

\- If the next character is \`)\`, consume both.

\- Otherwise, insert one missing \`)\`.

Then match that pair with an unmatched \`(\`.

If no opening parenthesis exists, insert one.

Finally, each unmatched opening parenthesis requires two more closing parentheses.

# Notes

 Use a greedy approach with a single pass.

 \`open\` tracks unmatched opening parentheses.

 \`ans\` tracks insertions already required.

 Every opening parenthesis needs two consecutive closing parentheses.

 If a closing parenthesis has no matching second \`)\`, insert one.

 If a closing pair has no unmatched opening parenthesis, insert one \`(\`.

 Each remaining opening parenthesis requires two closing parentheses.

 Final answer is \`ans + 2 * open\`.

 Time complexity is O(n).

 Space complexity is O(1).
