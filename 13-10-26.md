# 3727. Maximum Alternating Sum of Squares

Date Solved: 13 October 2026

Status: Solved

## Problem Statement

You are given an integer array `nums`. You may rearrange its elements in any order.

The alternating score of an array `arr` is defined as:

`score = arr[0]² - arr[1]² + arr[2]² - arr[3]² + ...`

Return the maximum possible alternating score after rearranging the elements.

---

## Examples

Example 1:

Input: `nums = [1,2,3]`

Output: `12`

Explanation:

One optimal rearrangement is `[2,1,3]`.

Alternating score:

`2² - 1² + 3² = 4 - 1 + 9 = 12`

Example 2:

Input: `nums = [1,-1,2,-2,3,-3]`

Output: `16`

Explanation:

One optimal rearrangement is `[-3,-1,-2,1,3,2]`.

Alternating score:

`(-3)² - (-1)² + (-2)² - 1² + 3² - 2²`

`= 9 - 1 + 4 - 1 + 9 - 4 = 16`

---

## Constraints

- `1 <= nums.length <= 10^5`
- `-4 * 10^4 <= nums[i] <= 4 * 10^4`

---

# Approach: Greedy + Sorting

The alternating score contains positive and negative terms:

`a[0]² - a[1]² + a[2]² - a[3]² + ...`

Since every element is squared, negative input values also produce nonnegative squares.

Let `squares` contain the squares of all elements, sorted in ascending order.

To maximize the score:

- Subtract the smallest `floor(n / 2)` squared values.
- Add the remaining larger squared values.

This works because the positions with positive signs should contain the largest squared values, while positions with negative signs should contain the smallest squared values.

Steps:

1. Calculate the square of every element and store it in a `long long` vector.
2. Sort the squared values in ascending order.
3. Initialize `ans = 0`.
4. For indices smaller than `n / 2`, subtract the squared values.
5. For all remaining indices, add the squared values.
6. Return `ans`.

---

# Complexity Analysis

Time Complexity: `O(n log n)`

Calculating the squares takes `O(n)`, and sorting takes `O(n log n)`.

Space Complexity: `O(n)`

We store the squared values in an additional vector.

---

# Solution

    class Solution {
    public:
        long long maxAlternatingSum(vector<int>& nums) {
            vector<long long> squares;

            for (int num : nums) {
                squares.push_back(1LL * num * num);
            }

            sort(squares.begin(), squares.end());

            long long ans = 0;
            int n = squares.size();

            for (int i = 0; i < n; i++) {
                if (i < n / 2) {
                    ans -= squares[i];
                } else {
                    ans += squares[i];
                }
            }

            return ans;
        }
    };

# Dry Run

Input: `nums = [1,2,3]`

Step 1: Calculate squares

`squares = [1,4,9]`

Step 2: Sort in ascending order

`squares = [1,4,9]`

Array length: `n = 3`

`n / 2 = 1`

Step 3: Calculate the alternating score

| Index | Squared Value | Operation | Running Sum |
|---|---:|---|---:|
| 0 | 1 | Subtract | -1 |
| 1 | 4 | Add | 3 |
| 2 | 9 | Add | 12 |

Final Output: `12`

Verification of Example 2:

Input: `nums = [1,-1,2,-2,3,-3]`

Squared values after sorting:

`squares = [1,1,4,4,9,9]`

There are `6 / 2 = 3` values to subtract.

Calculation:

`ans = -(1 + 1 + 4) + (4 + 9 + 9)`

`ans = -6 + 22 = 16`

Final Output: `16`

---

# Key Insight

The signs in the alternating sum are fixed, but the elements can be rearranged.

To maximize the result, assign the smallest squared values to negative positions and the largest squared values to positive positions.

Sorting allows us to do this efficiently.

---

# Notes

- Square each element before sorting because negative numbers become positive after squaring.
- Use `1LL * num * num` to perform multiplication using `long long`.
- Use `long long` for the answer to avoid integer overflow.
- For odd-sized arrays, there is one more positive position than negative positions.
- The solution runs in `O(n log n)` time and uses `O(n)` extra space.
- Verified against both provided examples: outputs are `12` and `16`.
