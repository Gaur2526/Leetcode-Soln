# 1021. Remove Outermost Parentheses

Date Solved: October 8, 2026

Status: Solved

## Problem Statement

A valid parentheses string is either:

\- Empty string \`""\`.

\- \`"(" + A + ")"\`, where \`A\` is a valid parentheses string.

\- \`A + B\`, where \`A\` and \`B\` are valid parentheses strings.

A valid parentheses string is called primitive if it is nonempty and cannot be split into two nonempty valid parentheses strings.

Given a valid parentheses string \`s\`, decompose it into primitive valid parentheses strings:

\`s = P1 + P2 + ... + Pk\`

Then remove the outermost parentheses from every primitive string and return the resulting string.

---

## Examples

### Example 1

Input:

s = "(()())(())"

Output:

"()()()"

Explanation:

The primitive decomposition is:

\`"(()())" + "(())"\`

Removing the outermost parentheses:

\`"()()" + "()"\`

Result:

\`"()()()"\`

### Example 2

Input:

s = "(()())(())(()(()))"

Output:

"()()()()(())"

Explanation:

The primitive decomposition is:

\`"(()())" + "(())" + "(()(()))"\`

After removing the outermost parentheses:

\`"()()" + "()" + "()(())"\`

Result:

\`"()()()()(())"\`

### Example 3

Input:

s = "()()"

Output:

""

Explanation:

The primitive decomposition is:

\`"()" + "()"\`

Removing the outermost parentheses from each primitive string gives:

\`"" + "" = ""\`

---

## Constraints

\- \`1 <= s.length <= 10^5\`

\- \`s[i]\` is either \`(\` or \`)\`.

\- \`s\` is a valid parentheses string.

---

# Approach

We use a balance counter to identify the outermost parentheses of every primitive component.

The variable:

\`balance\`

represents the current nesting depth.

The important observation is:

For every primitive parentheses string:

\- The outermost \`(\` changes the balance from \`0 -> 1\`.

\- The outermost \`)\` changes the balance from \`1 -> 0\`.

These two parentheses should be removed.

All other parentheses should be added to the answer.

### Step 1: Handle Opening Parenthesis

When we encounter \`(\`:

If:

\`balance > 0\`

then this is not an outermost opening parenthesis, so we keep it.

Then increase the balance:

\`balance++\`

If:

\`balance == 0\`

before processing the character, this is the outermost opening parenthesis, so we skip it.

### Step 2: Handle Closing Parenthesis

For a closing parenthesis, we first decrease the balance:

\`balance--\`

If after decreasing:

\`balance > 0\`

then this is not the outermost closing parenthesis, so we keep it.

If:

\`balance == 0\`

then we have reached the outermost closing parenthesis of the primitive component, so we skip it.

### Step 3: Primitive Boundary

Whenever:

\`balance == 0\`

we have completed one primitive parentheses string.

The next \`(\` starts a new primitive component.

The same logic automatically removes the outermost pair from every primitive component without explicitly splitting the string.

---

# Complexity

### Time Complexity

O(n)

We traverse the string exactly once.

### Space Complexity

O(n)

The answer string can contain up to O(n) characters.

---

# Solution

cpp

class Solution {

public:

    string removeOuterParentheses(string s) {

        string ans;

        int balance = 0;

        for (char ch : s) {

            if (ch == '(') {

                if (balance > 0)

                    ans += ch;

                balance++;

            } 
            else {

                balance--;

                if (balance > 0)

                    ans += ch;

            }

        }

        return ans;

    }

};

# Dry Run

Consider:

s = "(()())(())"

Initially:

\`balance = 0\`

\`ans = ""\`

### Primitive 1: "(()())"

First \`(\`:

balance = 0 → outermost opening → skip

balance = 1

Second \`(\`:

balance > 0 → keep

balance = 2

First \`)\`:

balance = 1

balance > 0 → keep

Second \`(\`:

balance > 0 → keep

balance = 2

Second \`)\`:

balance = 1

balance > 0 → keep

Final \`)\`:

balance = 0 → outermost closing → skip

Result:

\`()()\`

### Primitive 2: "(())"

First \`(\`:

balance = 0 → skip

balance = 1

Second \`(\`:

balance > 0 → keep

balance = 2

First \`)\`:

balance = 1

balance > 0 → keep

Final \`)\`:

balance = 0 → skip

Result:

\`()\`

Final answer:

\`"()()" + "()" = "()()()"\`

---

# Key Insight

The outermost parentheses of every primitive string are exactly the parentheses that occur when the balance moves:

\`0 -> 1\`

and:

\`1 -> 0\`

Therefore:

\- Skip \`(\` when the current balance is \`0\`.

\- Skip \`)\` when the balance becomes \`0\`.

Keep every other parenthesis.

This lets us solve the problem without explicitly finding or storing the primitive substrings.

---

# Notes

 Use a balance counter to track nesting depth.

 The opening parenthesis of a primitive component is encountered when \`balance == 0\`.

 The closing parenthesis of a primitive component is the one that makes \`balance == 0\`.

 Skip these two outermost parentheses.

 Keep all inner parentheses.

 There is no need to use a stack.

 There is no need to explicitly split the string into primitive components.

 Time complexity is O(n).

 Space complexity is O(n) for the result.
