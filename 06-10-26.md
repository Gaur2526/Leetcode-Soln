# 921. Minimum Add to Make Parentheses Valid

Date Solved: October 6, 2026

Status: Solved

## Problem Statement

Given a parentheses string \`s\`, in one move we can insert either \`(\` or \`)\` at any position.

Return the minimum number of moves required to make \`s\` a valid parentheses string.

A parentheses string is valid if:

\- It is empty.

\- It can be written as \`AB\`, where \`A\` and \`B\` are valid strings.

\- It can be written as \`(A)\`, where \`A\` is a valid string.

---

## Examples

### Example 1

Input:

s = "())"

Output:

1

Explanation:

We can insert one \`(\` or \`)\` to make the string valid.

For example:

\`()()\`

### Example 2

Input:

s = "((("

Output:

3

Explanation:

Three closing parentheses are required:

\`((()))\`

---

## Constraints

\- \`1 <= s.length <= 1000\`

\- \`s[i]\` is either \`(\` or \`)\`.

---

# Approach

We use a greedy approach and maintain the number of unmatched opening parentheses.

We use two variables:

\`balance\` → number of unmatched \`(\`.

\`ans\` → number of opening parentheses we need to insert because of unmatched \`)\`.

### Step 1: Handle Opening Parenthesis

When we see:

\`(\`

we increase the balance:

\`balance++\`

This means we have one more opening parenthesis available to match a future closing parenthesis.

### Step 2: Handle Closing Parenthesis

When we see:

\`)\`

there are two cases.

If:

\`balance > 0\`

we already have an unmatched opening parenthesis, so the closing parenthesis can match it.

Therefore:

\`balance--\`

If:

\`balance == 0\`

there is no opening parenthesis available to match this closing parenthesis.

We must insert an opening parenthesis.

Therefore:

\`ans++\`

### Step 3: Handle Remaining Opening Parentheses

After processing the entire string, if:

\`balance > 0\`

there are unmatched opening parentheses remaining.

Each one needs one closing parenthesis.

Therefore, the total answer is:

\`ans + balance\`

---

# Complexity

### Time Complexity

O(n)

We traverse the string exactly once.

### Space Complexity

O(1)

Only two integer variables are used.

---

# Solution

cpp

class Solution {

public:

    int minAddToMakeValid(string s) {

        int balance = 0;

        int ans = 0;

        for (char ch : s) {

            if (ch == '(') {

                balance++;

            } 
            else {

                if (balance > 0) {

                    balance--;

                } 
                else {

                    ans++;

                }

            }

        }

        return ans + balance;

    }

};

---

# Dry Run

Consider:

s = "())"

Initially:

\`balance = 0\`

\`ans = 0\`

### Character 1: \`(\`

Opening parenthesis:

\`balance++\`

Now:

\`balance = 1\`

\`ans = 0\`

### Character 2: \`)\`

There is an unmatched opening parenthesis.

So:

\`balance--\`

Now:

\`balance = 0\`

\`ans = 0\`

### Character 3: \`)\`

There is no unmatched opening parenthesis.

So we need to insert one \`(\`.

\`ans++\`

Now:

\`balance = 0\`

\`ans = 1\`

Final answer:

\`ans + balance = 1 + 0 = 1\`

---

# Another Dry Run

Consider:

s = "((("

Initially:

\`balance = 0\`

\`ans = 0\`

First \`(\`:

\`balance = 1\`

Second \`(\`:

\`balance = 2\`

Third \`(\`:

\`balance = 3\`

No closing parentheses are present.

Therefore, all 3 opening parentheses remain unmatched.

We need 3 closing parentheses.

Answer:

\`ans + balance = 0 + 3 = 3\`

---

# Key Insight

We only need to track unmatched parentheses.

When we see an unmatched \`)\`, we must insert an opening \`(\`.

When the string ends with unmatched \`(\`, we must insert closing \`)\` for each one.

Therefore:

\`answer = unmatched ')' + unmatched '('\`

This can be solved with a single pass and constant extra space.

---

# Notes

 Use \`balance\` to track unmatched opening parentheses.

 If \`(\` is encountered, increase \`balance\`.

 If \`)\` is encountered and \`balance > 0\`, decrease \`balance\`.

 If \`)\` is encountered and \`balance == 0\`, increment \`ans\`.

 Remaining \`balance\` values represent opening parentheses that need closing parentheses.

 Final answer is \`ans + balance\`.

 No stack is required.

 Time complexity is O(n).

 Space complexity is O(1).
