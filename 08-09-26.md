# 3870. Count Commas in Range

Date solved: 2026-09-08  Status: ✅ Accepted

## Problem

```
```

You are given an integer `n`.

Return the **total** number of commas used when writing all integers from `[1, n]` (inclusive) in **standard** number formatting.

In standard formatting:

* A comma is inserted after every three digits from the right.
* Numbers with fewer than 4 digits contain no commas.

```
```

## Examples

```
```

Example 1

```
Input

n = 1002

Output

3

Explanation

The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain one comma.

Therefore, the total number of commas is:

3
```

---

Example 2

```
Input

n = 998

Output

0

Explanation

All numbers from 1 to 998 have fewer than four digits.

Therefore, no commas are used.
```

```
```

## Constraints

```
```

1 <= n <= 10^5

```
```

## Approach

```
```

The important observation is that a comma is required only for numbers
having **4 or more digits**.

Numbers from `1` to `999` contain no commas.

Numbers from `1000` onwards contain exactly one comma because:

```
1000      -> "1,000"
1001      -> "1,001"
1002      -> "1,002"
```

Since the constraint is:

```
n <= 10^5
```

the largest possible number is `100000`, which contains only one comma.

Therefore, we only need to count how many numbers in the range `[1, n]`
are greater than or equal to `1000`.

If:

```
n < 1000
```

then there are no numbers containing commas.

So:

```
answer = 0
```

Otherwise, the numbers containing commas are:

```
1000, 1001, 1002, ..., n
```

The number of such numbers is:

```
n - 1000 + 1
```

which simplifies to:

```
n - 999
```

Therefore:

```
if n < 1000:

    answer = 0

else:

    answer = n - 999
```

Example:

```
n = 1002
```

The numbers containing commas are:

```
1000
1001
1002
```

Therefore:

```
answer = 1002 - 999

       = 3
```

Another example:

```
n = 998
```

Since:

```
998 < 1000
```

there are no numbers containing commas.

Therefore:

```
answer = 0
```

```
```

## Complexity

```
```

Time: O(1)

Space: O(1)

We directly calculate the number of integers that require a comma.

There is no need to iterate through all numbers from `1` to `n`.

```
```

## Solution

```
```

```cpp
class Solution {
public:
    int countCommas(int n) {
        if (n < 1000) {
            return 0;
        }

        return n - 999;
    }
};
```

```
```
