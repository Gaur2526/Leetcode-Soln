# 3723. Maximize Sum of Squares of Digits

Date Solved: 14 October 2026

Status: Solved

## Problem Statement

You are given two positive integers `num` and `sum`.

A positive integer `n` is called good if:

- The number of digits in `n` is exactly `num`.
- The sum of the digits of `n` is exactly `sum`.

The score of a good integer is the sum of the squares of its digits.

Return a string representing the good integer that achieves the maximum score. If multiple integers achieve the same maximum score, return the largest integer among them.

If no such integer exists, return an empty string `""`.

---

## Examples

Example 1:

Input: `num = 2, sum = 3`

Output: `"30"`

Explanation:

The good integers are `12`, `21`, and `30`.

Their scores are:

- `12`: \(1^2 + 2^2 = 5\)
- `21`: \(2^2 + 1^2 = 5\)
- `30`: \(3^2 + 0^2 = 9\)

The maximum score is `9`, achieved by `"30"`.

Example 2:

Input: `num = 2, sum = 17`

Output: `"98"`

Explanation:

The good integers are `89` and `98`.

Their scores are:

- `89`: \(8^2 + 9^2 = 145\)
- `98`: \(9^2 + 8^2 = 145\)

Both achieve the maximum score. Since `98` is larger than `89`, the answer is `"98"`.

Example 3:

Input: `num = 1, sum = 10`

Output: `""`

Explanation:

A single digit cannot have a value greater than `9`. Therefore, no valid integer exists.

---

## Constraints

- `1 <= num <= 2 * 10^5`
- `1 <= sum <= 2 * 10^6`

---

# Approach: Greedy

The objective is to maximize the sum of squared digits while keeping the total digit sum equal to `sum`.

The key observation is that larger digits produce a larger sum of squares. Therefore, we should place as much of the available digit sum as possible into each digit, starting from the left.

Each digit can have a maximum value of `9`.

Steps:

1. If `sum > 9 * num`, return an empty string because the required digit sum is impossible.
2. Initialize an empty answer string.
3. Iterate through all `num` digit positions.
4. At each position, choose the smaller of `9` and the remaining `sum`.
5. Append this digit to the answer.
6. Subtract the chosen digit from `sum`.
7. Once `sum` becomes zero, the remaining positions are filled with `0`.
8. Return the resulting string.

This greedy strategy maximizes the score and places larger digits first, ensuring the largest integer when multiple answers have the same maximum score.

---

# Complexity Analysis

Time Complexity: `O(num)`

We process each digit position exactly once.

Space Complexity: `O(num)`

The result string contains exactly `num` digits.

---

# Solution

    class Solution {
    public:
        string maxSumOfSquares(int num, int sum) {
            if (sum > 9 * num) {
                return "";
            }

            string ans = "";

            for (int i = 0; i < num; i++) {
                int digit = min(9, sum);
                ans += char('0' + digit);
                sum -= digit;
            }

            return ans;
        }
    };

# Dry Run

Input: `num = 2, sum = 17`

Initially:

- `num = 2`
- `sum = 17`
- `ans = ""`

Iteration 1:

- Choose `min(9, 17) = 9`.
- Append `9` to `ans`.
- Remaining sum: `17 - 9 = 8`.

Now:

`ans = "9", sum = 8`

Iteration 2:

- Choose `min(9, 8) = 8`.
- Append `8` to `ans`.
- Remaining sum: `8 - 8 = 0`.

Now:

`ans = "98", sum = 0`

Final Output: `"98"`

Score verification:

\(9^2 + 8^2 = 81 + 64 = 145\)

---

# Key Insight

To maximize the sum of squared digits, concentrate the available digit sum into the largest possible digits.

Since every digit is at most `9`, greedily choosing `min(9, sum)` at each position creates as many `9`s as possible, followed by the remaining digit and then zeros.

Placing the largest digits first also ensures the maximum integer among all answers with the same score.
