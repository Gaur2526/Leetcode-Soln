# 1520. Maximum Number of Non-Overlapping Substrings

Date Solved: September 18, 2026

Status: Solved

## Problem Statement

Given a string s of lowercase letters, find the maximum number of non-empty substrings that satisfy the following conditions:

1. The substrings do not overlap. For any two substrings s[i..j] and s[x..y], either j < x or i > y is true.

2. A substring that contains a certain character c must also contain all occurrences of c in the entire string.

If there are multiple solutions with the same maximum number of substrings, return the solution with the minimum total length.

It can be shown that there exists a unique solution with the minimum total length.

The substrings can be returned in any order.

---

## Examples

### Example 1

Input:

s = "adefaddaccc"

Output:

["e","f","ccc"]

Explanation:

The following are all the possible valid substrings:

["adefaddaccc", "adefadda", "ef", "e", "f", "ccc"]

If we choose the entire string, we cannot choose anything else, so we get only one substring.

If we choose "adefadda", we can also choose "ccc", giving two substrings.

However, "ef" is not optimal because it can be split into two valid substrings:

"e" and "f"

Therefore, the optimal solution is:

["e","f","ccc"]

which contains three substrings.

### Example 2

Input:

s = "abbaccd"

Output:

["d","bb","cc"]

Explanation:

The solution:

["d","bb","cc"]

contains three substrings.

Although:

["d","abba","cc"]

also contains three substrings, its total length is larger.

Therefore, the required answer is:

["d","bb","cc"]

---

## Constraints

- 1 <= s.length <= 10^5

- s contains only lowercase English letters.

---

# Approach

The key idea is to convert the problem into an interval selection problem.

For every character, we first find its:

- First occurrence

- Last occurrence

If we want to create a valid substring starting at the first occurrence of a character, the substring must contain all occurrences of every character that appears inside it.

We can therefore construct the smallest valid substring for every character.

After generating these valid intervals, the problem becomes:

> Select the maximum number of non-overlapping intervals.

If multiple selections contain the same number of intervals, we want the one with the minimum total length.

This can be solved using a greedy strategy based on the earliest ending interval.

---

## Step 1: Find First and Last Occurrences

Create two arrays:

first[26]

and:

last[26]

where:

- first[c] stores the first occurrence of character c.

- last[c] stores the last occurrence of character c.

For example, for:

s = "adefaddaccc"

we get ranges such as:

a -> [0, 7]

d -> [1, 3]

e -> [2, 2]

f -> [3, 3]

c -> [8, 10]

---

## Step 2: Construct a Valid Interval

For each character c, start with:

l = first[c]

and:

r = last[c]

Now examine every character between l and r.

Suppose we encounter character x.

There are two possibilities.

### Case 1: first[x] < l

This means character x occurs before our starting position.

Since the substring contains x, it would need to contain that earlier occurrence as well.

But that would require extending the substring to the left, which is impossible because we fixed:

l = first[c]

Therefore, this interval is invalid.

### Case 2: first[x] >= l

The substring can contain character x.

However, it must contain all occurrences of x.

Therefore, we extend the right boundary:

r = max(r, last[x])

We continue scanning until the complete interval has been processed.

If we never encounter a character whose first occurrence is before l, then the interval is valid.

---

## Step 3: Generate Minimal Valid Intervals

For every character that appears in the string, we generate its smallest valid interval.

For example:

s = "adefaddaccc"

Some valid intervals are:

"e" -> [2,2]

"f" -> [3,3]

"ccc" -> [8,10]

The interval:

"ef" -> [2,3]

is also valid, but it is not useful in the optimal solution because it can be replaced by two smaller non-overlapping intervals:

"e"

and:

"f"

Therefore, we want to select intervals carefully.

---

## Step 4: Sort Intervals

Sort the valid intervals by:

1. Ending position in ascending order.

2. If two intervals have the same ending position, sort by starting position in descending order.

The second condition ensures that if two intervals end at the same position, we prefer the shorter interval.

For example:

[1,5]

and:

[3,5]

both end at 5.

We prefer:

[3,5]

because it has the smaller length.

---

## Step 5: Greedy Selection

After sorting, iterate through the intervals.

Maintain:

prevEnd

which represents the ending position of the previously selected substring.

For every interval:

[l,r]

we select it if:

l > prevEnd

This guarantees that the new substring does not overlap with the previously selected substring.

After selecting it:

prevEnd = r

Because we always consider intervals with the earliest ending positions first, we leave as much space as possible for future substrings.

This maximizes the number of non-overlapping substrings.

---

## Why Greedy Works

This problem has the same core idea as the activity selection / interval scheduling problem.

Suppose two possible intervals are:

A = [l1, r1]

and:

B = [l2, r2]

with:

r1 < r2

Choosing A leaves at least as much room for future intervals as choosing B.

Therefore, choosing the interval that finishes earliest can never reduce the maximum number of intervals we can select.

For intervals with the same ending position, choosing the one with the larger starting position gives the smaller total length.

---

## Detailed Steps

1. Create arrays first[26] and last[26].

2. Traverse the string and find the first and last occurrence of every character.

3. For every character that appears in the string:

   - Set l = first[c].

   - Set r = last[c].

4. Scan the substring from l to r.

5. For every character encountered:

   - If first[x] < l, mark the interval as invalid.

   - Otherwise, extend r using r = max(r, last[x]).

6. If the interval is valid, add [r,l] to the list of intervals.

7. Sort all valid intervals by:

   - Ending position ascending.

   - Starting position descending when ending positions are equal.

8. Initialize:

   prevEnd = -1

9. Iterate through all intervals.

10. If:

   l > prevEnd

   select the interval.

11. Add the corresponding substring to the answer.

12. Update:

   prevEnd = r

13. Return the selected substrings.

---

# Complexity

Let n = s.length().

There are at most 26 different characters.

## Time Complexity

Finding first and last occurrences takes:

O(n)

For each of the at most 26 characters, we scan its possible interval.

Therefore:

O(26 * n)

which is effectively:

O(n)

Sorting at most 26 intervals takes:

O(26 log 26)

Therefore, the overall complexity is:

Time: O(n)

because the alphabet size is fixed at 26.

## Space Complexity

We use arrays of size 26 and store at most 26 intervals.

Therefore:

Space: O(1)

excluding the output.

# Solution

cpp

class Solution {

public:

    vector<string> maxNumOfSubstrings(string s) {

        int n = s.size();

        vector<int> first(26, n);

        vector<int> last(26, -1);

        // Find first and last occurrence of every character

        for (int i = 0; i < n; i++) {

            int c = s[i] - 'a';

            first[c] = min(first[c], i);

            last[c] = i;

        }

        vector<pair<int, int>> intervals;

        // Generate the smallest valid interval for each character

        for (int c = 0; c < 26; c++) {

            if (last[c] == -1)

                continue;

            int l = first[c];

            int r = last[c];

            bool valid = true;

            for (int i = l; i <= r; i++) {

                int x = s[i] - 'a';

                // This character has an occurrence before l

                // so the interval cannot be valid.

                if (first[x] < l) {

                    valid = false;

                    break;

                }

                // We must include every occurrence of this character.

                r = max(r, last[x]);

            }

            if (valid) {

                intervals.push_back({r, l});

            }

        }

        // Sort by ending position.

        // For equal ending positions, prefer the larger start

        // because it gives a shorter substring.

        sort(intervals.begin(), intervals.end(),

             [](const pair<int, int>& a,

                const pair<int, int>& b) {

                 if (a.first != b.first)

                     return a.first < b.first;

                 return a.second > b.second;

             });

        vector<string> ans;

        int prevEnd = -1;

        // Greedily select non-overlapping intervals

        for (auto [r, l] : intervals) {

            if (l > prevEnd) {

                ans.push_back(s.substr(l, r - l + 1));

                prevEnd = r;

            }

        }

        return ans;

    }

};

# Key Insight

The most important observation is:

> If a substring contains a character, it must contain every occurrence of that character.

Therefore, for every character, we can determine the smallest possible valid substring containing it.

Once these valid substrings are converted into intervals, the problem becomes an interval scheduling problem.

We greedily choose intervals that finish earliest because doing so leaves the maximum possible space for future substrings.

For intervals with the same ending position, we prefer the one with the larger starting position because it has the smaller total length.

So the overall strategy is:

First/Last Occurrences -> Valid Intervals -> Sort -> Greedy Selection

# Notes

- A valid substring must contain all occurrences of every character present inside it.

- We only need to consider substrings starting at the first occurrence of a character.

- If a character inside the candidate interval has an occurrence before the starting position, that candidate is invalid.

- The right boundary may need to expand while scanning the interval.

- There are at most 26 candidate intervals because the string contains only lowercase English letters.

- After generating the intervals, the problem becomes a standard non-overlapping interval selection problem.

- Choosing the earliest-ending interval maximizes the number of selected substrings.

- For equal ending positions, choosing the shorter interval helps satisfy the minimum-total-length requirement.

- The final solution runs in effectively O(n) time because the alphabet size is fixed at 26.
