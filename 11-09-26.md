# 3483. Unique 3-Digit Even Numbers

* **Date Solved:** September 11, 2026
* **Status:** Solved
* **Difficulty:** Easy

## Problem Statement

You are given an array of digits called `digits`.

Your task is to determine the number of **distinct three-digit even numbers** that can be formed using these digits.

### Rules

1. Each copy of a digit can be used **at most once** per number.
2. The number must be a **three-digit number**, so the first digit cannot be `0`.
3. The number must be **even**, so the last digit must be one of:
   `0, 2, 4, 6, 8`.
4. Different arrangements that produce the same number should only be counted once.

## Examples

### Example 1

**Input:**

```text
digits = [1,2,3,4]
```

**Output:**

```text
12
```

The valid numbers are:

```text
124, 132, 134, 142,
214, 234,
312, 314, 324, 342,
412, 432
```

### Example 2

**Input:**

```text
digits = [0,2,2]
```

**Output:**

```text
2
```

The valid numbers are:

```text
202, 220
```

The digit `2` can be used twice because there are two copies of it.

### Example 3

**Input:**

```text
digits = [6,6,6]
```

**Output:**

```text
1
```

Only:

```text
666
```

can be formed.

### Example 4

**Input:**

```text
digits = [1,3,5]
```

**Output:**

```text
0
```

There is no even digit available for the last position.

## Constraints

* `3 <= digits.length <= 10`
* `0 <= digits[i] <= 9`

---

## Approach

Since every digit is between `0` and `9`, we can simply try every possible three-digit number from `100` to `999`.

For each number:

1. Check whether it is **even**.
2. Extract its three digits.
3. Check whether those three digits can be constructed from the given `digits` array without using any copy more than once.
4. If possible, count the number.

Because we iterate through the numbers themselves, every number is naturally considered only once, so we don't have to explicitly maintain a set of generated numbers.

### Frequency Array

Create a frequency array:

```text
freq[d]
```

where `freq[d]` represents how many copies of digit `d` are available.

For a number such as `202`:

```text
2 0 2
```

we need:

```text
freq[2] >= 2
freq[0] >= 1
```

We can check this by counting the required occurrences of each digit.

### Why This Works

There are only:

```text
999 - 100 + 1 = 900
```

three-digit numbers.

Checking at most 900 numbers is extremely small, so brute force is both simple and efficient.

---

## Complexity

Let `N` be the number of digits in the input.

We check at most 900 numbers, and each check takes constant time because there are only three digits.

### Time Complexity

```text
O(900 × 3) = O(1)
```

More generally, this can be considered:

```text
O(10^3)
```

### Space Complexity

We use a frequency array of size 10:

```text
O(10) = O(1)
```

---

## Solution

```cpp
class Solution {
public:
    int totalNumbers(vector<int>& digits) {
        vector<int> freq(10, 0);

        // Store frequency of each digit
        for (int digit : digits) {
            freq[digit]++;
        }

        int ans = 0;

        // Try every possible three-digit number
        for (int num = 100; num <= 999; num++) {

            // The number must be even
            if (num % 2 != 0) {
                continue;
            }

            int x = num;
            vector<int> need(10, 0);

            // Extract its three digits
            for (int i = 0; i < 3; i++) {
                need[x % 10]++;
                x /= 10;
            }

            // Check whether we have enough copies
            bool possible = true;

            for (int digit = 0; digit <= 9; digit++) {
                if (need[digit] > freq[digit]) {
                    possible = false;
                    break;
                }
            }

            if (possible) {
                ans++;
            }
        }

        return ans;
    }
};
```

## Step-by-Step Example

Consider:

```text
digits = [0,2,2]
```

The frequency array is:

```text
0 → 1
2 → 2
```

Now consider the number:

```text
202
```

Its required digits are:

```text
0 → 1
2 → 2
```

The available frequencies are exactly sufficient:

```text
need[0] = 1 <= freq[0] = 1
need[2] = 2 <= freq[2] = 2
```

Therefore, `202` is valid.

Now consider:

```text
222
```

It requires:

```text
need[2] = 3
```

but we only have:

```text
freq[2] = 2
```

Therefore, `222` cannot be formed.

The answer is:

```text
2
```

---

## Notes

* Checking numbers from `100` to `999` automatically handles the **no leading zero** requirement.
* Checking `num % 2 == 0` automatically ensures the last digit is even.
* Using a frequency array correctly handles duplicate digits.
* We don't need a `set` because every three-digit number is generated exactly once.
* This is a good example where a simple brute-force solution is preferable because the search space is very small.
