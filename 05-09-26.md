# 3904. Smallest Stable Index II

Date solved: 2026-09-05  Status: ✅ Accepted

## Problem

    \`\`\`

    You are given an integer array nums of length n and an integer k.

    For each index i, define its instability score as:

        max(nums[0..i]) - min(nums[i..n - 1])

    An index i is called stable if its instability score is less than or equal

    to k.

    Return the smallest stable index.

    If no such index exists, return -1.

    \`\`\`

## Examples

    \`\`\`

    Example 1

        Input

        nums = [5,0,1,4]

        k = 3

        Output

        3

        Explanation

        At index 0:

            max([5]) - min([5,0,1,4])

            \= 5 - 0

            \= 5

        At index 1:

            max([5,0]) - min([0,1,4])

            \= 5 - 0

            \= 5

        At index 2:

            max([5,0,1]) - min([1,4])

            \= 5 - 1

            \= 4

        At index 3:

            max([5,0,1,4]) - min([4])

            \= 5 - 4

            \= 1

        The first index with instability score <= 3 is index 3.

    Example 2

        Input

        nums = [3,2,1]

        k = 1

        Output

        -1

        Explanation

        At every index, the maximum prefix value is 3 and the minimum

        suffix value is 1.

        Therefore, the instability score is:

            3 - 1 = 2

        Since 2 > 1, no index is stable.

    Example 3

        Input

        nums = [0]

        k = 0

        Output

        0

        Explanation

        The instability score is:

            0 - 0 = 0

        Since 0 <= 0, index 0 is stable.

    \`\`\`

## Constraints

    \`\`\`

    1 <= nums.length <= 105

    0 <= nums[i] <= 109

    0 <= k <= 109

    \`\`\`

## Approach

    \`\`\`

    The important observation is that the instability score consists of two

    independent parts:

        max(nums[0..i])      -> prefix maximum

        min(nums[i..n-1])    -> suffix minimum

    We can precompute the minimum value for every suffix using a suffixMin

    array.

    For every index i:

        suffixMin[i] = minimum value from nums[i] to nums[n-1]

    We build suffixMin from right to left.

    For example:

        nums = [5,0,1,4]

        suffixMin = [0,0,1,4]

    Then we scan the array from left to right while maintaining the maximum

    value seen so far.

        prefixMax = max(nums[0..i])

    For every index:

        instability = prefixMax - suffixMin[i]

    If:

        instability <= k

    then the current index is stable.

    Since we scan from left to right, the first stable index is automatically

    the smallest stable index.

    If no index satisfies the condition, return -1.

    \`\`\`

## Complexity

    \`\`\`

    Time: O(n)

    Space: O(n)

    \`\`\`

## Solution

    \`\`\`

    class Solution {

    public:

        int firstStableIndex(vector\<int>& nums, int k) {

            int n = nums.size();

            vector\<int> suffixMin(n);

            suffixMin[n - 1] = nums[n - 1];

            // Build suffix minimum array

            for (int i = n - 2; i >= 0; i--) {

                suffixMin[i] = min(nums[i], suffixMin[i + 1]);

            }

            int prefixMax = nums[0];

            // Find the first stable index

            for (int i = 0; i < n; i++) {

                prefixMax = max(prefixMax, nums[i]);

                int instability = prefixMax - suffixMin[i];

                if (instability <= k) {

                    return i;

                }

            }

            return -1;

        }

    };

    \`\`\`

## Notes

    \`\`\`

    Key insight:

        instability score =

            prefix maximum - suffix minimum

    We calculate the suffix minimums by scanning from right to left.

    Then, while scanning from left to right, we maintain the prefix maximum.

    Example:

        nums = [5,0,1,4]

        k = 3

        suffixMin = [0,0,1,4]

        i = 0

            prefixMax = 5

            instability = 5 - 0 = 5

        i = 1

            prefixMax = 5

            instability = 5 - 0 = 5

        i = 2

            prefixMax = 5

            instability = 5 - 1 = 4

        i = 3

            prefixMax = 5

            instability = 5 - 4 = 1

    At index 3:

        instability = 1 <= k = 3

    Therefore:

        answer = 3

    The main trick is separating the problem into:

        Prefix Maximum + Suffix Minimum

    This lets us check every index in O(1) time after preprocessing.

    Therefore:

        Build suffix minimum -> O(n)

        Find prefix maximum and check stability -> O(n)

        Total -> O(n)

    \`\`\`
