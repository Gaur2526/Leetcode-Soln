# 1401. Circle and Rectangle Overlapping

Date Solved: September 19, 2026
Status: Solved

## Problem Statement

You are given a circle represented by (radius, xCenter, yCenter) and an axis-aligned rectangle represented by (x1, y1, x2, y2).

Return true if the circle and rectangle overlap. In other words, check if there is any point that belongs to both the circle and the rectangle.

---

## Examples

### Example 1

Input:
radius = 1, xCenter = 0, yCenter = 0, x1 = 1, y1 = -1, x2 = 3, y2 = 1

Output:
true

Explanation:
The circle and rectangle share the point (1, 0).

### Example 2

Input:
radius = 1, xCenter = 1, yCenter = 1, x1 = 1, y1 = -3, x2 = 2, y2 = -1

Output:
false

### Example 3

Input:
radius = 1, xCenter = 0, yCenter = 0, x1 = -1, y1 = 0, x2 = 0, y2 = 1

Output:
true

---

## Constraints

- 1 <= radius <= 2000
- -10^4 <= xCenter, yCenter <= 10^4
- -10^4 <= x1 < x2 <= 10^4
- -10^4 <= y1 < y2 <= 10^4

---

# Approach

The key idea is to find the point inside the rectangle that is closest to the center of the circle.

If the circle's center is already inside the rectangle, the closest point is the center itself.

Otherwise, we can find the closest point by clamping the circle center's x and y coordinates to the rectangle boundaries.

### Step 1: Find the closest X coordinate

Clamp xCenter between x1 and x2.

closestX = max(min(xCenter, x2), x1)

### Step 2: Find the closest Y coordinate

Clamp yCenter between y1 and y2.

closestY = max(min(yCenter, y2), y1)

### Step 3: Calculate the squared distance

Calculate the squared Euclidean distance between the circle center and the closest point:

distanceSquared = (xCenter - closestX)^2 + (yCenter - closestY)^2

### Step 4: Compare with the radius

The circle and rectangle overlap if the closest point is inside or exactly on the circle.

Therefore:

distanceSquared <= radius^2

Using squared distances avoids calculating the square root.

---

# Complexity

### Time Complexity

O(1)

Only a constant number of calculations are performed.

### Space Complexity

O(1)

Only a few variables are used.

---

# Solution

cpp
class Solution {
public:
    bool checkOverlap(int radius, int xCenter, int yCenter, int x1, int y1, int x2, int y2) {
        
        auto clamp = [](int value, int min_val, int max_val) {
            return max(min(value, max_val), min_val);
        };

        int closestX = clamp(xCenter, x1, x2);
        int closestY = clamp(yCenter, y1, y2);

        int distanceSquared = (xCenter - closestX) * (xCenter - closestX) +
                              (yCenter - closestY) * (yCenter - closestY);

        return distanceSquared <= radius * radius;
    }
};

# Dry Run

Example:

radius = 1

xCenter = 0, yCenter = 0

Rectangle:

x1 = 1, y1 = -1, x2 = 3, y2 = 1

Step 1: Find closest X

closestX = clamp(0, 1, 3) = 1

Step 2: Find closest Y

closestY = clamp(0, -1, 1) = 0

So the closest point is:

(1, 0)

Step 3: Calculate squared distance

distanceSquared = (0 - 1)^2 + (0 - 0)^2

= 1

Step 4: Compare with radius squared

radius^2 = 1^2 = 1

Since:

1 <= 1

The circle and rectangle overlap.

Answer: true

---

# Key Insight

The important idea is to find the closest point on the rectangle to the circle's center.

Clamping each coordinate independently gives this closest point.

Then we only need to check whether the distance between the circle center and this point is less than or equal to the radius.

---

# Notes

- No need to check all points of the rectangle.
- Clamping handles cases where the circle center is inside or outside the rectangle.
- Compare squared distances instead of using sqrt().
- Boundary contact counts as overlap, so use <= instead of <.
