# 20. Valid Parentheses

Date Solved: October 1, 2026

Status: Solved

## Problem Statement

Given a string s containing only:

 (

 )

 {

 }

 [

 ]

Determine whether the input string is valid.

A string is valid if:

1. Every opening bracket is closed by the same type of bracket.

2. Brackets are closed in the correct order.

3. Every closing bracket has a corresponding opening bracket.

---

## Examples

### Example 1

Input:

s = "()"

Output:

true

### Example 2

Input:

s = "()[]{}"

Output:

true

### Example 3

Input:

s = "(]"

Output:

false

### Example 4

Input:

s = "([])"

Output:

true

### Example 5

Input:

s = "([)]"

Output:

false

---

## Constraints

 1 <= s.length <= 10^4

 s consists of parentheses only: ()[]{ }.

---

# Approach

We use a stack because brackets must be closed in the reverse order in which they are opened.

For example:

([{}])

The opening brackets are:

(

[

{

The closing brackets must appear in reverse order:

}

]

)

A stack naturally follows this Last-In-First-Out order.

### Step 1: Handle Opening Brackets

If the current character is:

(, [, or {

push it into the stack.

For example:

([{

Stack:

[ top

{

(

### Step 2: Handle Closing Brackets

When we encounter a closing bracket, first check if the stack is empty.

If the stack is empty, there is no corresponding opening bracket, so return false.

Otherwise, check the top element.

For:

)

the top must be:

(

For:

]

the top must be:

[

For:

}

the top must be:

{

If the types do not match, return false.

If they match, pop the opening bracket.

### Step 3: Check the Stack

After processing the entire string, the stack must be empty.

If the stack is empty:

The string is valid.

If the stack still contains brackets:

Some opening brackets were never closed, so the string is invalid.

---

# Complexity

### Time Complexity

O(n)

We traverse the string once.

### Space Complexity

O(n)

In the worst case, all characters can be opening brackets and stored in the stack.

---

# Solution

cpp

class Solution {

public:

    bool isValid(string s) {

        stack<char> st;

        for (char ch : s) {

            if (ch == '(' || ch == '[' || ch == '{') {

                st.push(ch);

            } 
            else {

                if (st.empty())

                    return false;

                char top = st.top();

                if ((ch == ')' && top != '(') ||

                    (ch == ']' && top != '[') ||

                    (ch == '}' && top != '{')) {

                    return false;

                }

                st.pop();

            }

        }

        return st.empty();

    }

};

# Key Insight

The most important idea is:

The last opening bracket must be the first one to close.

This is exactly the behavior of a stack:

Last In → First Out

Therefore, whenever we see a closing bracket, we only need to compare it with the top of the stack.

---

# Notes

 Use a stack to keep track of unmatched opening brackets.

 Push every opening bracket.

 For every closing bracket, check the stack top.

 The closing bracket must match the most recently opened bracket.

 Pop the matching opening bracket.

 If a closing bracket appears when the stack is empty, return false.

 If the types do not match, return false.

 After processing the string, the stack must be empty.

 Time complexity is O(n).

 Space complexity is O(n).
