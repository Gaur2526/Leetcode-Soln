# 835. Image Overlap

**Date Solved:** September 13, 2026

**Status:** Solved

## Problem Statement

You are given two binary square matrices `img1` and `img2` of size `n x n`.

You can translate one image by sliding all its `1` bits left, right, up, and/or down any number of units. Rotation is not allowed.

After translating, any `1` bits that move outside the matrix boundaries are erased.

The overlap is the number of positions where both images contain a `1`.

Return the largest possible overlap after any translation.

---

## Examples

### Example 1

```text

Input:

img1 = [[1,1,0],[0,1,0],[0,1,0]]

img2 = [[0,0,0],[0,1,1],[0,0,1]]

Output: 3

```

The optimal translation moves `img1` one position to the right and one position down.

The three `1` bits overlap with `img2`.

---

### Example 2

```text

Input:

img1 = [[1]]
img2 = [[1]]

Output: 1

```

---

### Example 3

```text

Input:

img1 = [[0]]
img2 = [[0]]

Output: 0

```

---

## Constraints

* `1 <= n <= 30`

* `n == img1.length == img1[i].length`

* `n == img2.length == img2[i].length`

* `img1[i][j]` is either `0` or `1`

* `img2[i][j]` is either `0` or `1`

---

# Approach

The straightforward solution tries every possible translation and checks every cell individually, resulting in `O(n^4)` time.

Since `n <= 30`, we can optimize the solution using **bit manipulation**.

Each row contains at most 30 elements, so we can represent an entire row using a `uint32_t` bitmask.

For example:

```text

[1, 0, 1, 1]

```

can be represented as:

```text

1011

```

Each bit represents whether the corresponding position contains `1`.

This allows us to perform horizontal translations using bit shifts and calculate overlaps using bitwise AND.

---

## Step 1: Convert Rows Into Bitmasks

For every row, we store the positions containing `1` as set bits.

For every `1` at column `j`:

```cpp

a[i] |= (1u << j);

```

We do the same for `img2`.

For example:

```text

[1, 0, 1, 0, 1]

```

becomes:

```text

10101

```

Because `n <= 30`, the entire row safely fits inside a 32-bit integer.

---

## Step 2: Try Every Possible Translation

A translation is determined by:

```text

dr = vertical shift
dc = horizontal shift

```

Both shifts can range from:

```text

-(n - 1) to +(n - 1)

```

Therefore, we try every possible combination of vertical and horizontal shifts.

```cpp

for (int dr = -(n - 1); dr <= n - 1; dr++) {
for (int dc = -(n - 1); dc <= n - 1; dc++) {
...
}
}

```

---

## Step 3: Handle Vertical Translation

For a row `i` in `img1`, after applying vertical shift `dr`, its new position is:

```cpp

int j = i + dr;

```

If:

```cpp

j < 0 || j >= n

```

then that row has moved outside the matrix and cannot contribute to the overlap.

Otherwise, row `i` of `img1` is compared with row `j` of `img2`.

---

## Step 4: Handle Horizontal Translation

The horizontal movement can be performed directly on the bitmask.

If `dc > 0`, shift left:

```cpp

x <<= dc;

```

If `dc < 0`, shift right:

```cpp

x >>= -dc;

```

This shifts the entire row using a single bit operation instead of moving every cell individually.

---

## Step 5: Calculate the Overlap

After applying the horizontal shift, we compare the translated row with the corresponding row of `img2`.

```cpp

x & b[j]

```

The bitwise AND keeps a `1` only at positions where both rows contain a `1`.

For example:

```text

x = 101101
b[j] = 111001

AND = 101001

```

The number of overlapping positions is then calculated using:

```cpp

__builtin_popcount(x & b[j])

```

This counts the number of set bits in the intersection.

---

## Step 6: Update the Maximum Answer

For every translation, calculate the total overlap across all rows.

Then update:

```cpp

ans = max(ans, overlap);

```

After checking all possible translations, `ans` contains the maximum possible overlap.

---

# Complexity

Let `n` be the size of the matrix.

## Number of Translations

There are:

```text

(2n - 1) * (2n - 1)

```

possible translations.

Therefore:

```text

O(n^2)

```

translations are considered.

## Work Per Translation

For each translation, we process at most `n` rows.

Therefore:

```text

O(n)

```

work is performed for every translation.

## Overall Complexity

Therefore:

```text

Time: O(n^3)
Space: O(n)

```

This improves the straightforward cell-by-cell solution from `O(n^4)` to `O(n^3)`.

---

# Solution

```cpp

class Solution {

public:

int largestOverlap(vector<vector<int>>& img1, vector<vector<int>>& img2) {

    int n = img1.size();

    vector<uint32_t> a(n, 0), b(n, 0);

    // Convert each row into a bitmask.
    for (int i = 0; i < n; i++) {

        for (int j = 0; j < n; j++) {

            if (img1[i][j])
                a[i] |= (1u << j);

            if (img2[i][j])
                b[i] |= (1u << j);

        }

    }

    int ans = 0;

    // Try every vertical shift.
    for (int dr = -(n - 1); dr <= n - 1; dr++) {

        // Try every horizontal shift.
        for (int dc = -(n - 1); dc <= n - 1; dc++) {

            int overlap = 0;

            for (int i = 0; i < n; i++) {

                int j = i + dr;

                // Translated row is outside the matrix.
                if (j < 0 || j >= n)
                    continue;

                uint32_t x = a[i];

                // Apply horizontal translation.
                if (dc > 0)
                    x <<= dc;
                else
                    x >>= -dc;

                // Count overlapping 1s.
                overlap += __builtin_popcount(x & b[j]);

            }

            ans = max(ans, overlap);

        }

    }

    return ans;

}

};

```

# Dry Run

Consider:

```text

img1 = [
[1,1,0],
[0,1,0],
[0,1,0]
]

img2 = [
[0,0,0],
[0,1,1],
[0,0,1]
]

```

Represent each row as a bitmask:

```text

img1:

110
010
010

```

and:

```text

img2:

000
110
001

```

Now consider the translation:

```text

dr = 1
dc = 1

```

The first row of `img1`:

```text

110

```

is shifted right by one position:

```text

011

```

and moved down by one row.

The second row:

```text

010

```

becomes:

```text

001

```

after the horizontal shift.

The third row moves outside the matrix.

The translated image becomes:

```text

000
011
001

```

which is exactly aligned with:

```text

000
011
001

```

Therefore:

```text

overlap = 3

```

and:

```text

ans = 3

```

# Key Insight

The key observation is that `n <= 30`, so an entire binary row can fit inside a 32-bit integer.

Instead of processing every cell individually, we represent each row as a bitmask and use:

```cpp

x & b[j]

```

to find all overlapping `1` positions at once.

Then:

```cpp

__builtin_popcount(x & b[j])

```

counts those overlapping positions.

Horizontal translations are handled using bit shifting:

```cpp

x <<= dc;
x >>= -dc;

```

Therefore, the problem can be solved in:

```text

O(n^3) time
O(n) space

```

instead of the brute-force `O(n^4)` approach.

---

# Notes

* `uint32_t` is sufficient because `n <= 30`.

* Only translation is allowed; rotation is not required.

* Vertical translation is handled by matching different rows.

* Horizontal translation is handled using bit shifting.

* `__builtin_popcount()` efficiently counts the overlapping `1` bits.

* The main optimization is representing an entire binary row as a bitmask.
