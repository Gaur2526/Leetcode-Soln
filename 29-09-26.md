# 2267. Check if There Is a Valid Parentheses String Path

Date Solved: September 29, 2026

Status: Solved

## Problem Statement

You are given an m x n matrix of parentheses grid.

A valid parentheses string path must:

 Start from the upper-left cell (0,0).

 End at the bottom-right cell (m-1,n-1).

 Move only down or right.

 Form a valid parentheses string.

A parentheses string is valid if:

 It is ().

 It can be written as AB, where both A and B are valid.

 It can be written as (A), where A is valid.

Return true if there exists at least one valid parentheses string path.


## Examples

### Example 1

Input:

grid = [["(","(","("],[")","(",")"],["(","(",")"],["(","(",")"]]

Output:

true

Explanation:

There are paths that form valid parentheses strings such as:

()(() )

and:

((()))

### Example 2

Input:

grid = [[")",")"],["(","("]]

Output:

false

Explanation:

The possible paths form:

))(

and:

)((

Neither is a valid parentheses string.


## Constraints

 m == grid.length

 n == grid[i].length

 1 <= m, n <= 100

 grid[i][j] is either ( or ).


# Approach

This is a dynamic programming problem where we track the current parentheses balance.

For a valid parentheses string:

 ( increases the balance by 1.

 ) decreases the balance by 1.

 The balance can never become negative.

 At the end, the balance must be exactly 0.

We define:

dp[i][j][bal]

as:

Whether it is possible to reach cell (i,j) with a current balance of bal.

### Step 1: Check Path Length

Every path from the top-left to the bottom-right contains exactly:

m + n - 1

cells.

A valid parentheses string must have an even number of characters.

Therefore, if:

(m + n - 1) % 2 == 1

we can immediately return false.

### Step 2: Check Starting Cell

The first character must be (.

If the starting cell contains ), the balance immediately becomes negative.

So:

grid[0][0] == ')'

means the answer is false.

Otherwise:

dp[0][0][1] = true

because we have seen one opening parenthesis.

### Step 3: Move Through the Grid

For every cell, we can arrive from:

 The cell above.

 The cell on the left.

If the current character is (:

newBalance = balance + 1

If the current character is ):

newBalance = balance - 1

If the new balance becomes negative, that state is invalid.

### Step 4: Final State

At the bottom-right cell, we need:

balance = 0

Therefore:

dp[m-1][n-1][0]

being true means a valid parentheses path exists.


# Complexity

Let:

L = m + n - 1

be the maximum possible balance dimension.

### Time Complexity

O(m × n × (m + n))

For every cell, we check every possible balance.

### Space Complexity

O(m × n × (m + n))

We store a boolean state for every cell and every possible balance.


# Solution

cpp

class Solution {

public:

    bool hasValidPath(vector<vector<char>>& grid) {

        int m = grid.size();

        int n = grid[0].size();

        // Valid parentheses string must have even length

        if ((m + n - 1) % 2 == 1)

            return false;

        // Maximum possible balance

        int len = m + n - 1;

        vector<vector<vector<bool>>> dp(

            m,

            vector<vector<bool>>(n, vector<bool>(len + 1, false))

        );

        // Starting cell must be '('

        if (grid[0][0] == ')')

            return false;

        dp[0][0][1] = true;

        for (int i = 0; i < m; i++) {

            for (int j = 0; j < n; j++) {

                if (i == 0 && j == 0)

                    continue;

                for (int bal = 0; bal <= len; bal++) {

                    int newBal;

                    if (grid[i][j] == '(')

                        newBal = bal + 1;

                    else

                        newBal = bal - 1;

                    if (newBal < 0 || newBal > len)

                        continue;

                    if (i > 0 && dp[i - 1][j][bal])

                        dp[i][j][newBal] = true;

                    if (j > 0 && dp[i][j - 1][bal])

                        dp[i][j][newBal] = true;

                }

            }

        }

        return dp[m - 1][n - 1][0];

    }

};

Consider:

grid =

]


One possible valid path produces:

((()))

Track the balance:

( → balance = 1

( → balance = 2

( → balance = 3

) → balance = 2

) → balance = 1

) → balance = 0

The balance never becomes negative and ends at 0.

dp[m-1][n-1][0] = true

Answer:

true


# Key Insight

A parentheses string is valid if and only if:

 Its balance never becomes negative.

 Its final balance is 0.

So instead of storing the entire path, we only need to remember the current balance.

The DP state becomes:

position + current balance

This allows us to check all possible paths without explicitly constructing every path.


# Notes

 Use DP with the current parentheses balance as the third state.

 The balance represents the number of unmatched opening parentheses.

 Never allow the balance to become negative.

 The first cell must contain (.

 A valid parentheses string must have even length.

 Every path contains exactly m + n - 1 characters.

 The final balance must be exactly 0.

 Time complexity is O(m × n × (m+n)).

 Space complexity is O(m × n × (m+n)).
