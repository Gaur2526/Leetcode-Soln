# 3871. Count Commas in Range II

Date solved: 2026-09-09  Status: ✅ Accepted

## Problem

```

```

You are given an integer `n`.

Return the **total** number of commas used when writing all integers from `[1, n]` (inclusive) in **standard** number formatting.

In standard formatting:

* A comma is inserted after every three digits from the right.

* Numbers with fewer than 4 digits contain no commas.

```

```

## Examples

```

```

Example 1

```

Input

n = 1002

Output

3

Explanation

The numbers `"1,000"`, `"1,001"`, and `"1,002"` each contain one comma.

Therefore, the total number of commas is:

3

```

**---**

Example 2

```

Input

n = 998

Output

0

Explanation

All numbers from 1 to 998 have fewer than four digits.

Therefore, no commas are used.

```

```

```

## Constraints

```

```

1 <= n <= 10^15

```

```

## Approach

```

```

The important observation is that unlike the previous problem, `n` can
be as large as `10^15`.

Therefore, a number can contain multiple commas.

For example:

```

1,000

    -> 1 comma

1,000,000

    -> 2 commas

1,000,000,000

    -> 3 commas

```

Instead of checking every number individually, we count the contribution
of each comma position separately.

The first comma appears starting from:

```

1000

```

Every number from `1000` to `n` contains the first comma.

Therefore, the number of numbers containing the first comma is:

```

n - 1000 + 1

```

The second comma appears starting from:

```

1000000

```

Every number from `1000000` to `n` contains the second comma.

Therefore, its contribution is:

```

n - 1000000 + 1

```

Similarly, the third comma starts from:

```

1000000000

```

and contributes:

```

n - 1000000000 + 1

```

These comma positions occur at powers of `1000`:

```

1000
1000000
1000000000
1000000000000
1000000000000000

```

Therefore, we iterate over every power of `1000` that is less than or
equal to `n`.

For every such value `power`, we add:

```

n - power + 1

```

to the answer.

For example:

```

n = 1002

```

Only one comma position is possible:

```

power = 1000

```

Therefore:

```

answer = 1002 - 1000 + 1

       = 3

```

Another example:

```

n = 1000000

```

There are two comma positions.

First comma:

```

1000 to 1000000

```

Contribution:

```

1000000 - 1000 + 1

= 999001

```

Second comma:

```

1000000 to 1000000

```

Contribution:

```

1000000 - 1000000 + 1

= 1

```

Therefore:

```

answer = 999001 + 1

       = 999002

```

The key point is that a number containing multiple commas is counted
once for each comma position.

For example:

```

1,000,000

```

contains two commas.

It is counted once when:

```

power = 1000

```

and once when:

```

power = 1000000

```

Therefore, summing the contribution of every comma position gives the
total number of commas.

```

```

## Complexity

```

```

Time: O(log₁₀ n)

Space: O(1)

We only iterate through powers of `1000`.

Since `n <= 10^15`, the number of iterations is very small.

No additional data structures are required.

```

```

## Solution

```

```

```cpp

class Solution {

public:

    long long countCommas(long long n) {

        long long ans = 0;

        for (long long power = 1000; power <= n; power *= 1000) {

            ans += n - power + 1;

        }

        return ans;

    }

};

```

```

```

## Notes

```

```

Key insight:

```

Count each comma position independently instead of checking every number.

```

The comma positions start at:

```

1000
1000000
1000000000
1000000000000
1000000000000000

```

For every comma threshold `power`, all numbers from `power` to `n`
contain that particular comma.

Therefore:

```

contribution = n - power + 1

```

The answer is the sum of these contributions:

```

answer = Σ (n - power + 1)

```

for every:

```

power = 1000, 1000000, 1000000000, ...

```

as long as:

```

power <= n

```

Example:

```

n = 1002

power = 1000

answer = 1002 - 1000 + 1

       = 3

```

Example:

```

n = 998

Since:

    1000 > 998

there are no comma positions.

Therefore:

    answer = 0

```

For a larger value:

```

n = 1000000

```

The number `"1,000,000"` contains two commas.

The first comma is counted for:

```

power = 1000

```

The second comma is counted for:

```

power = 1000000

```

Therefore, both commas are included in the final answer.

The main trick is:

```

Do not count commas number by number.

Count every comma position independently.

```

Since the largest possible `n` is `10^15`, we use `long long` to safely
store the answer and intermediate values.

Therefore:

```

Time -> O(log₁₀ n)

Space -> O(1)

```
