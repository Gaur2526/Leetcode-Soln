# 2472. Maximum Number of Non-overlapping Palindrome Substrings

**Date Solved:** September 15, 2026

**Status:** Solved

## Problem Statement

You are given a string `s` and a **positive** integer `k`.

Select a set of **non-overlapping** substrings from the string `s` that satisfy the following conditions:

- The length of each substring is **at least** `k`.
- Each substring is a **palindrome**.

Return the **maximum** number of substrings in an optimal selection.

A **substring** is a contiguous sequence of characters within the string.

---

## Examples

### Example 1

Input:

`s = "abaccdbbd", k = 3`

Output:

`2`

Explanation:

We can select the substrings `"aba"` and `"dbbd"`.

Both are palindromes and have a length of at least `k = 3`.

It can be shown that we cannot find a selection with more than two valid substrings.

### Example 2

Input:

`s = "adbcda", k = 2`

Output:

`0`

Explanation:

There is no palindrome substring of length at least `2`.

---

## Constraints

- `1 <= k <= s.length <= 2000`
- `s` consists of lowercase English letters.

---

# Approach

We can solve this problem using **Dynamic Programming** in two stages:

1. Precompute whether every substring is a palindrome.
2. Use another DP to find the maximum number of non-overlapping palindromic substrings.

The main challenge is ensuring that the selected palindromes do not overlap.

---

## Step 1: Precompute Palindromes

Define:

`pal[l][r]`

as `true` if the substring `s[l...r]` is a palindrome.

A substring is a palindrome when:

- `s[l] == s[r]`
- The substring inside it is also a palindrome.

Therefore:

`pal[l][r] = (s[l] == s[r]) && pal[l + 1][r - 1]`

For substrings of length `1` or `2`, we can handle them directly.

The complete recurrence is:

`pal[l][r] = s[l] == s[r] && (r - l <= 1 || pal[l + 1][r - 1])`

We fill this table by increasing substring length.

---

## Step 2: Dynamic Programming

Define:

`dp[i]`

as the maximum number of valid non-overlapping palindromic substrings that can be selected from the first `i` characters.

So:

`dp[i]`

represents the answer for:

`s[0...i-1]`

At every position, we have two choices.

---

## Choice 1: Skip the Current Character

We can simply ignore the character at index `i - 1`.

Therefore:

`dp[i] = dp[i - 1]`

---

## Choice 2: Select a Palindrome Ending at `i - 1`

Suppose we select a palindrome starting at index `j` and ending at `i - 1`.

Its length is:

`i - j`

The substring is valid only if:

`i - j >= k`

and:

`pal[j][i - 1] == true`

If we select this palindrome, then all previously selected palindromes must end before index `j`.

That is exactly what `dp[j]` represents.

Therefore:

`dp[i] = max(dp[i], dp[j] + 1)`

---

## Step 3: Why the Substrings Are Non-overlapping

When we select the palindrome:

`[j, i - 1]`

we add it to the solution represented by:

`dp[j]`

Since `dp[j]` only considers the first `j` characters, it can only contain substrings ending before index `j`.

Therefore, the new palindrome cannot overlap with any previously selected palindrome.

---

## Detailed Steps

1. Let `n = s.length()`.
2. Create a 2D array `pal[n][n]`.
3. Fill the palindrome table using the recurrence:
   `pal[l][r] = s[l] == s[r] && (r - l <= 1 || pal[l + 1][r - 1])`.
4. Create a DP array `dp[n + 1]`.
5. Initialize all values of `dp` to `0`.
6. Iterate `i` from `1` to `n`.
7. Initially set:
   `dp[i] = dp[i - 1]`
   because we can always skip the current character.
8. Try every possible starting position `j` for a substring ending at `i - 1`.
9. If:
   - `i - j >= k`
   - `pal[j][i - 1] == true`
   
   then update:
   `dp[i] = max(dp[i], dp[j] + 1)`.
10. Return `dp[n]`.

---

# Complexity

Let `n = s.length()`.

## Time Complexity

Building the palindrome table takes:

`O(n²)`

The DP also checks every possible pair of starting and ending positions:

`O(n²)`

Therefore:

`Time: O(n²)`

## Space Complexity

The palindrome table requires:

`O(n²)`

The DP array requires:

`O(n)`

Therefore:

`Space: O(n²)`

---

# Solution

```cpp
class Solution {
public:
    int maxPalindromes(string s, int k) {
        int n = s.size();

        // pal[l][r] tells whether s[l...r] is a palindrome
        vector<vector<bool>> pal(n, vector<bool>(n, false));

        // Build the palindrome table
        for (int len = 1; len <= n; len++) {
            for (int l = 0; l + len - 1 < n; l++) {
                int r = l + len - 1;

                if (s[l] == s[r] && (len <= 2 || pal[l + 1][r - 1])) {
                    pal[l][r] = true;
                }
            }
        }

        // dp[i] = maximum number of non-overlapping
        // palindromic substrings using first i characters
        vector<int> dp(n + 1, 0);

        for (int i = 1; i <= n; i++) {
            // Option 1: Skip the current character
            dp[i] = dp[i - 1];

            // Option 2: Select a palindrome ending at i - 1
            for (int j = 0; j <= i - k; j++) {
                if (pal[j][i - 1]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
        }

        return dp[n];
    }
};
