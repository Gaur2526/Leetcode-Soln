# 3551. Minimum Swaps to Sort by Digit Sum

Date Solved: 17 October 2026

Status: Solved

## Problem Statement

You are given an array `nums` containing distinct positive integers.

Sort the array in increasing order according to these rules:

1. The integer with the smaller digit sum comes first.
2. If two integers have the same digit sum, the smaller integer comes first.

Return the minimum number of swaps required to rearrange `nums` into this sorted order.

A swap exchanges the values at two distinct positions in the array.

---

## Examples

Example 1:

Input: `nums = [37,100]`

Output: `1`

Explanation:

Digit sums:

- `37` → `3 + 7 = 10`
- `100` → `1 + 0 + 0 = 1`

The sorted array is `[100,37]`.

Swap `37` and `100` once.

Minimum swaps: `1`

Example 2:

Input: `nums = [22,14,33,7]`

Output: `0`

Explanation:

Digit sums:

- `22` → `4`
- `14` → `5`
- `33` → `6`
- `7` → `7`

The array is already sorted according to the required rules.

Minimum swaps: `0`

Example 3:

Input: `nums = [18,43,34,16]`

Output: `2`

Explanation:

Digit sums:

- `18` → `9`
- `43` → `7`
- `34` → `7`
- `16` → `7`

Among the elements with digit sum `7`, the correct order is `16, 34, 43`.

The sorted array is `[16,34,43,18]`.

We can perform two swaps:

1. Swap `18` and `16` → `[16,43,34,18]`
2. Swap `43` and `34` → `[16,34,43,18]`

Minimum swaps: `2`

---

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- All elements of `nums` are distinct.

---

# Approach: Sorting + Cycle Decomposition

We first sort the elements according to the required rules. Then we determine the minimum number of swaps needed to transform the original arrangement into the sorted arrangement.

Step 1: Calculate digit sums

Create a helper function `digitSum()` that calculates the sum of the digits of an integer.

For example:

`digitSum(37) = 3 + 7 = 10`

Step 2: Store the original indices

For each element, store a tuple containing:

`(digitSum, value, originalIndex)`

For example, for `nums = [37,100]`, we get:

- `(10, 37, 0)`
- `(1, 100, 1)`

Step 3: Sort the tuples

Sort the tuples in ascending order.

C++ sorts tuples lexicographically, so the order is determined by:

1. Digit sum
2. Integer value
3. Original index

Since all input integers are distinct, the original index does not affect the required ordering.

Step 4: Find cycles

After sorting, each element has a destination position.

Use a `visited` array to identify cycles in the permutation.

If a cycle contains `cycleSize` elements, it requires:

`cycleSize - 1` swaps.

For example, a cycle of length `3` requires `2` swaps.

Step 5: Calculate the answer

Traverse every position:

- Skip it if already visited.
- Skip it if the element is already in its correct position.
- Otherwise, traverse its cycle and count the elements.
- Add `cycleSize - 1` to the answer.

Return the total number of swaps.

---

# Complexity Analysis

Time Complexity: `O(n log n)`

- Calculating digit sums takes `O(n log M)`, where `M` is the maximum element.
- Sorting the tuples takes `O(n log n)`.
- Cycle traversal takes `O(n)`.

Since each number has at most 10 digits, digit-sum calculation is effectively constant time. Therefore, the overall complexity is `O(n log n)`.

Space Complexity: `O(n)`

We store the tuples and use a visited array, both requiring linear space.

# Solution

    class Solution {
    public:
        int digitSum(int num) {
            int sum = 0;

            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }

            return sum;
        }

        int minSwaps(vector<int>& nums) {
            int n = nums.size();

            vector<tuple<int, int, int>> arr;

            for (int i = 0; i < n; i++) {
                arr.push_back({digitSum(nums[i]), nums[i], i});
            }

            sort(arr.begin(), arr.end());

            vector<bool> visited(n, false);
            int swaps = 0;

            for (int i = 0; i < n; i++) {
                if (visited[i] || get<2>(arr[i]) == i) {
                    continue;
                }

                int cycleSize = 0;
                int j = i;

                while (!visited[j]) {
                    visited[j] = true;
                    j = get<2>(arr[j]);
                    cycleSize++;
                }

                if (cycleSize > 1) {
                    swaps += cycleSize - 1;
                }
            }

            return swaps;
        }
    };

# Dry Run

Input: `nums = [18,43,34,16]`

Step 1: Calculate digit sums

| Value | Digit Sum | Original Index |
|---|---:|---:|
| 18 | 9 | 0 |
| 43 | 7 | 1 |
| 34 | 7 | 2 |
| 16 | 7 | 3 |

Step 2: Sort by digit sum, then value

Sorted tuples:

- `(7,16,3)`
- `(7,34,2)`
- `(7,43,1)`
- `(9,18,0)`

Sorted array:

`[16,34,43,18]`

Original indices in sorted order:

`[3,2,1,0]`

Step 3: Find cycles

Initially:

`visited = [false,false,false,false]`

Cycle 1: Start at index 0

- Index `0` points to original index `3`.
- Index `3` points to original index `0`.

Cycle: `0 → 3 → 0`

Cycle size: `2`

Required swaps:

`2 - 1 = 1`

Running total: `1`

Cycle 2: Start at index 1

- Index `1` points to original index `2`.
- Index `2` points to original index `1`.

Cycle: `1 → 2 → 1`

Cycle size: `2`

Required swaps:

`2 - 1 = 1`

Running total: `2`

Final Output: `2`

# Key Insight

Sorting determines where every element must go, but counting misplaced elements does not directly give the minimum number of swaps.

The permutation formed by the original indices can be divided into independent cycles.

A cycle containing `m` elements requires exactly `m - 1` swaps to place all its elements correctly.

Therefore:

`Minimum Swaps = Sum of (Cycle Size - 1)`

---

# Notes

- Digit sum is the primary sorting key.
- The integer value is the secondary sorting key.
- Store original indices before sorting to track each element's destination.
- Use `tuple<int, int, int>` to store digit sum, value, and original index.
- A cycle of length `1` requires no swaps.
- The algorithm runs in `O(n log n)` time and uses `O(n)` extra space.
- Verified manually against all three provided examples: outputs are `1`, `0`, and `2`.
