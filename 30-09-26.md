# 1111. Maximum Nesting Depth of Two Valid Parentheses Strings

Date Solved: September 30, 2026

Status: Solved

## Problem Statement

Given a valid parentheses string seq, split it into two disjoint subsequences A and B.

Both A and B must be valid parentheses strings.

For every character in seq:

 answer[i] = 0 means the character belongs to A.

 answer[i] = 1 means the character belongs to B.

The goal is to minimize:

max(depth(A), depth(B))

The subsequences do not need to be contiguous.

---

## Examples

### Example 1

Input:

seq = "(()())"

Output:

[0,1,1,1,1,0]

Explanation:

The characters are divided between the two subsequences so that both remain valid and their maximum nesting depth is minimized.

### Example 2

Input:

seq = "()(())()"

Output:

[0,0,0,1,1,0,1,1]

---

## Constraints

 1 <= seq.size <= 10000

 seq is a valid parentheses string.

---

# Approach

The key idea is to divide the nesting levels between the two subsequences.

We maintain the current nesting depth using:

depth

For every parenthesis, we assign it to group 0 or 1 based on whether the current depth is odd or even.

This effectively distributes alternate nesting levels between the two groups.

### Step 1: Handle Opening Parenthesis

When we encounter (, the nesting depth increases first.

So:

depth++

Then assign:

depth % 2

If the depth is odd, the character goes to group 1.

If the depth is even, the character goes to group 0.

### Step 2: Handle Closing Parenthesis

For a closing parenthesis ), the current depth still represents the level that is being closed.

Therefore, we assign:

depth % 2

first.

Then decrease the depth:

depth--

This ensures that every opening and its corresponding closing parenthesis go to the same group.

### Step 3: Why This Works

Suppose the original string has nesting depth:

1 -> 2 -> 3 -> 4

We distribute these levels as:

Group 0:

levels 2, 4

Group 1:

levels 1, 3

Therefore, each group receives approximately half of the original nesting depth.

Both resulting subsequences remain valid because matching opening and closing parentheses are assigned to the same group.

---

# Complexity

### Time Complexity

O(n)

We traverse the string exactly once.

### Space Complexity

O(n)

The answer array contains one value for every character.

---

# Solution

cpp

class Solution {

public:

    vector<int> maxDepthAfterSplit(string seq) {

        vector<int> ans;

        int depth = 0;

        for (char ch : seq) {

            if (ch == '(') {

                depth++;

                ans.push_back(depth % 2);

            } else {

                ans.push_back(depth % 2);

                depth--;

            }

        }

        return ans;

    }

};

# Key Insight

We do not need to actually construct the two subsequences.

The important observation is:

Parentheses at alternating nesting levels can be assigned to different groups.

Use:

depth % 2

to decide the group.

For (:

depth++ then assign.

For ):

assign first, then depth--.

This guarantees that matching parentheses are placed in the same group.

---

# Notes

 Use the current nesting depth to decide the group.

 Use depth % 2 to alternate between groups.

 For (, increase depth before assigning.

 For ), assign before decreasing depth.

 Matching parentheses always receive the same group.

 The two subsequences remain valid VPS strings.

 The maximum nesting depth is approximately divided between the two groups.

 Any optimal valid split can be returned.

 Time complexity is O(n).

 Space complexity is O(n).
