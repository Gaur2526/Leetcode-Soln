# 2333. Minimum Sum of Squared Difference

Date Solved: October 10, 2026

Status: Solved

## Problem Statement

You are given two integer arrays \`nums1\` and \`nums2\`, both of length \`n\`.

The sum of squared differences is defined as:

\`sum((nums1[i] - nums2[i])^2)\`

You are also given two integers \`k1\` and \`k2\`.

You can modify elements of:

\- \`nums1\` by increasing or decreasing any element by 1, at most \`k1\` times.

\- \`nums2\` by increasing or decreasing any element by 1, at most \`k2\` times.

Return the minimum possible sum of squared differences after performing these operations.

---

## Examples

### Example 1

Input:

nums1 = [1,2,3,4]

nums2 = [2,10,20,19]

k1 = 0

k2 = 0

Output:

579

Explanation:

No modifications are allowed.

Squared differences:

\`(1-2)^2 + (2-10)^2 + (3-20)^2 + (4-19)^2\`

\`= 1 + 64 + 289 + 225\`

Answer:

579

### Example 2

Input:

nums1 = [1,4,10,12]

nums2 = [5,8,6,9]

k1 = 1

k2 = 1

Output:

43

Explanation:

One optimal choice is to increase \`nums1[0]\` by 1 and increase \`nums2[2]\` by 1.

The resulting arrays are:

nums1 = [2,4,10,12]

nums2 = [5,8,7,9]

Squared differences:

\`9 + 16 + 9 + 9 = 43\`

---

## Constraints

\- \`n == nums1.length == nums2.length\`

\- \`1 <= n <= 10^5\`

\- \`0 <= nums1[i], nums2[i] <= 10^5\`

\- \`0 <= k1, k2 <= 10^9\`

---

# Approach

We use a greedy strategy with a frequency array.

The key observation is that reducing a larger absolute difference gives a greater reduction in the squared sum than reducing a smaller difference.

For example:

\`5^2 - 4^2 = 9\`

but:

\`2^2 - 1^2 = 3\`

Therefore, we should always reduce the largest differences first.

### Step 1: Calculate Absolute Differences

For every index:

\`diff[i] = abs(nums1[i] - nums2[i])\`

Combine the operation budgets:

\`k = k1 + k2\`

An operation on either array can reduce the corresponding absolute difference by 1, so we can treat both budgets as one.

Also calculate the sum of all absolute differences.

If:

\`k >= total\`

we can reduce every difference to zero, so the answer is zero.

### Step 2: Build a Frequency Array

The maximum possible absolute difference is:

\`100000\`

Create:

\`freq[d]\`

which stores how many elements have absolute difference \`d\`.

For example:

Differences:

\`[2, 4, 3, 2, 1]\`

Frequencies:

\- \`freq[1] = 1\`

\- \`freq[2] = 2\`

\- \`freq[3] = 1\`

\- \`freq[4] = 1\`

### Step 3: Reduce the Largest Differences

Traverse differences from \`100000\` down to \`1\`.

For each difference \`d\`, move as many elements as possible from bucket \`d\` to bucket \`d-1\`.

The number of moves is:

\`min(k, freq[d])\`

After moving those elements:

\- Decrease \`freq[d]\`.

\- Increase \`freq[d-1]\`.

\- Decrease the remaining operation budget.

This processes the largest differences first without repeatedly scanning the entire array.

### Step 4: Calculate the Final Answer

After using the available operations, calculate:

\`sum(d * d * freq[d])\`

Each difference contributes its square multiplied by its frequency.

Use \`long long\` because the squared sum can exceed the range of a 32-bit integer.

---

# Complexity

Let \`D = 100000\`, the maximum possible absolute difference.

### Time Complexity

O(n + D)

We calculate the differences in O(n) and process the frequency array in O(D).

### Space Complexity

O(D)

The frequency array has \`100001\` entries.

---

# Solution

cpp

class Solution {

public:

    long long minSumSquareDiff(vector<int>& nums1, vector<int>& nums2,

                               int k1, int k2) {

        long long k = 1LL * k1 + k2;

        vector<int> freq(100001, 0);

        long long total = 0;

        for (int i = 0; i < nums1.size(); i++) {

            int d = abs(nums1[i] - nums2[i]);

            freq[d]++;

            total += d;

        }

        if (k >= total)

            return 0;

        for (int d = 100000; d > 0 && k > 0; d--) {

            if (freq[d] == 0)

                continue;

            long long moves = min(k, 1LL * freq[d]);

            freq[d] -= moves;

            freq[d - 1] += moves;

            k -= moves;

        }

        long long ans = 0;

        for (int d = 1; d <= 100000; d++) {

            ans += 1LL * d * d * freq[d];

        }

        return ans;

    }

};

# Dry Run

Consider:

nums1 = [11,12,13,14,15]

nums2 = [13,16,16,12,14]

k1 = 3

k2 = 6

### Step 1: Calculate Differences

Absolute differences:

\`[2,4,3,2,1]\`

Total difference:

\`2 + 4 + 3 + 2 + 1 = 12\`

Available operations:

\`k = 3 + 6 = 9\`

Since 9 is less than 12, we cannot make every difference zero.

### Step 2: Reduce the Largest Differences

Initial differences:

\`[2,4,3,2,1]\`

Reduce the largest differences first:

\- Reduce \`4\` to \`3\`.

\- Reduce \`3\` to \`2\`.

\- Reduce \`3\` to \`2\`.

Continue until all 9 operations are used.

The final differences can be:

\`[1,1,1,0,0]\`

Their sum is:

\`1 + 1 + 1 = 3\`

### Step 3: Calculate Squared Sum

\`1^2 + 1^2 + 1^2 + 0^2 + 0^2\`

\`= 1 + 1 + 1\`

Final answer:

3

---

# Key Insight

Always reduce the largest absolute differences first.

Because the objective is the sum of squares, reducing a large difference gives a greater improvement.

A frequency array lets us perform these reductions efficiently by moving counts from difference \`d\` to difference \`d-1\`.

This avoids sorting the array
