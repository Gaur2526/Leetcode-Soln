# 2265. Count Nodes Equal to Average of Subtree

Date solved: 2026-09-10  Status: ✅ Accepted

## Problem

```

```

You are given the `root` of a binary tree.

Return the number of nodes where the value of the node is equal to the average of the values in its subtree.

The average of `n` elements is the sum of the `n` elements divided by `n` and rounded down to the nearest integer.

A subtree of `root` is a tree consisting of `root` and all of its descendants.

```

```

## Examples

```

```

Example 1

```

Input

root = [4,8,5,0,1,null,6]

Output

5

```

Explanation

For the node with value `4`:

```

(4 + 8 + 5 + 0 + 1 + 6) / 6

= 24 / 6

= 4

```

Since the average is equal to the node value `4`, this node is counted.

For the node with value `5`:

```

(5 + 6) / 2

= 11 / 2

= 5

```

Since the average is rounded down to the nearest integer, the average is `5`.

Therefore, node `5` is counted.

For the node with value `0`:

```

0 / 1 = 0

```

Therefore, node `0` is counted.

For the node with value `1`:

```

1 / 1 = 1

```

Therefore, node `1` is counted.

For the node with value `6`:

```

6 / 1 = 6

```

Therefore, node `6` is counted.

The total number of nodes satisfying the condition is:

```

5

```

---

Example 2

```

Input

root = [1]

Output

1

```

Explanation

The subtree contains only the node `1`.

Therefore:

```

1 / 1 = 1

```

The node value is equal to the average, so the node is counted.

Therefore, the answer is:

```

1

```

```

```

## Constraints

```

```

The number of nodes in the tree is in the range `[1, 1000]`.

`0 <= Node.val <= 1000`

```

```

## Approach

```

```

The important observation is that for every node, we need to know two things about its subtree:

```

1. Sum of all values in the subtree

2. Number of nodes in the subtree

```

We can calculate both values using DFS.

A node depends on the information from its left and right subtrees, so we use postorder traversal.

The traversal order is:

```

Left Subtree

Right Subtree

Current Node

```

For every node, we first recursively calculate the sum and number of nodes in its left subtree.

Then we recursively calculate the sum and number of nodes in its right subtree.

After that, we calculate the information for the current subtree.

The subtree sum is:

```

sum = root->val + leftSum + rightSum

```

The number of nodes in the subtree is:

```

nodes = 1 + leftNodes + rightNodes

```

We can then calculate the average using integer division:

```

average = sum / nodes

```

Since the problem requires the average to be rounded down, normal integer division in C++ gives the required result.

If:

```

root->val == sum / nodes

```

then the current node satisfies the condition, so we increment the answer.

For example, consider the node `5`:

```

        5
         
          6

```

The right subtree contains:

```

sum = 6

nodes = 1

```

For the current node:

```

sum = 5 + 6

    = 11

```

and:

```

nodes = 1 + 1

      = 2

```

Therefore:

```

average = 11 / 2

        = 5

```

Since:

```

5 == 5

```

this node is counted.

The same process is performed for every node in the tree.

Instead of traversing the subtree again for every node, we return the calculated sum and node count from each recursive call.

Therefore, every node is processed only once.

The recursive function returns:

```

{sum, number of nodes}

```

to its parent.

For a null node:

```

sum = 0

nodes = 0

```

This makes it easy to calculate the information for leaf nodes as well.

For a leaf node with value `x`:

```

sum = x

nodes = 1

average = x / 1

        = x

```

Therefore, every leaf node is always counted.

The key idea is:

```

Calculate subtree sum and subtree size using postorder DFS.

Then check whether:

node value == subtree sum / subtree size

```

```

```

## Complexity

```

```

Time: O(n)

Space: O(h)

```

Every node is visited exactly once during the DFS traversal.

Therefore, the time complexity is:

```

O(n)

```

where `n` is the number of nodes in the tree.

The recursive DFS uses the call stack.

If `h` is the height of the tree, the recursion uses:

```

O(h)

```

space.

In the worst case, the tree can be completely skewed, making:

```

h = n

```

Therefore, the worst-case space complexity is:

```

O(n)

```

No additional data structures proportional to the number of nodes are required.

```

```

## Solution

```

```

```cpp

class Solution {

public:

    int count = 0;

    pair<int, int> dfs(TreeNode* root) {

        if (root == nullptr)
            return {0, 0};

        auto left = dfs(root->left);
        auto right = dfs(root->right);

        int sum = root->val + left.first + right.first;

        int nodes = 1 + left.second + right.second;

        if (root->val == sum / nodes)
            count++;

        return {sum, nodes};

    }

    int averageOfSubtree(TreeNode* root) {

        dfs(root);

        return count;

    }

};

```

## Notes

```

```

Key insight:

```

For every node, calculate:

    subtree sum

    subtree node count

```

Then check:

```

node value == subtree sum / subtree node count

```

Postorder DFS is useful because the current node needs information from both of its children.

The recursive function returns:

```

{sum, count}

```

where:

```

sum   = sum of all values in the subtree

count = number of nodes in the subtree

```

For every node:

```

sum = root->val + leftSum + rightSum

count = 1 + leftCount + rightCount

```

Then:

```

average = sum / count

```

If:

```

root->val == average

```

we increment the answer.

For a leaf node:

```

sum = node value

count = 1

average = node value / 1

        = node value

```

Therefore, every leaf node is counted.

For example:

```

Node = 6

Sum = 6

Count = 1

Average = 6 / 1

        = 6

```

So node `6` is counted.

For node `5` with child `6`:

```

Sum = 5 + 6

    = 11

Count = 2

Average = 11 / 2

        = 5

```

So node `5` is also counted.

The main trick is:

```

Do not calculate the subtree sum separately for every node.

Calculate it once using DFS and return the result to the parent.

```

This prevents repeated traversal of the same nodes.

The overall process is:

```

DFS(left)

DFS(right)

Calculate current subtree sum

Calculate current subtree count

Check average

Return {sum, count}

```

Therefore:

```

Time -> O(n)

Space -> O(h)

```

where `h` is the height of the binary tree.
