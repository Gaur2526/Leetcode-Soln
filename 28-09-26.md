# 1614. Maximum Nesting Depth of the Parentheses

Date Solved: September 28, 2026

Status: Solved

## Problem Statement

Given a valid parentheses string s, return the nesting depth of s.

The nesting depth is the maximum number of nested parentheses.

For example:

(1+(2*3)+((8)/4))+1

has a maximum nesting depth of 3 because 8 is inside 3 nested pairs of parentheses.


## Examples

### Example 1

Input:

s = "(1+(2*3)+((8)/4))+1"

Output:

3

Explanation:

Digit 8 is inside 3 nested parentheses.

### Example 2

Input:

s = "(1)+((2))+(((3)))"

Output:

3

Explanation:

Digit 3 is inside 3 nested parentheses.

### Example 3

Input:

s = "()(())((()()))"

Output:

3


## Constraints

1 <= s.length <= 100

s consists of digits 0-9 and characters +, -, *, /, (, and )`.

It is guaranteed that s is a valid parentheses string.


# Approach

We use two variables:

depth → stores the current nesting depth.

maxDepth → stores the maximum nesting depth seen so far.

We scan the string from left to right.

### Step 1: Handle Opening Parenthesis

When we encounter (, we increase the current depth.

For example:

(

depth becomes 1.

If another ( appears:

((

depth becomes 2.

After increasing the depth, we update maxDepth.

### Step 2: Handle Closing Parenthesis

When we encounter ), we decrease the current depth because one level of nesting has ended.

For example:

(1)

After reading (:

depth = 1

After reading ):

depth = 0

### Step 3: Track Maximum Depth

Every time we open a parenthesis, we check:

maxDepth = max(maxDepth, depth)

The largest value reached by depth is the answer.


# Complexity

### Time Complexity

O(n)

We traverse the string exactly once.

### Space Complexity

O(1)

Only two integer variables are used.


# Solution

cpp

class Solution {

public:

    int maxDepth(string s) {

        int depth = 0;

        int maxDepth = 0;

        for (char ch : s) {

            if (ch == '(') {

                depth++;

                maxDepth = max(maxDepth, depth);

            } 

            else if (ch == ')') {

                depth--;

            }

        }

        return maxDepth;

    }

};

# Key Insight

The current nesting depth is simply the number of currently open parentheses.

So:

( → depth++

) → depth--

The maximum value of depth during the traversal is the answer.

No stack is required because we only care about the number of active nested parentheses, not their individual positions.


# Notes

 Use a simple counter instead of a stack.

 Increase the counter when encountering (.

 Decrease the counter when encountering ).

 Track the maximum value reached by the counter.

 Since the input is guaranteed to be valid, the depth will never become negative.

 The solution runs in O(n) time and O(1) space.
